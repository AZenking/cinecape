# ADR-0009：会话化播放网关与受控媒体转换

状态：Accepted（2026-10-25 维护者接受，依据见 plan.md T001 接受记录；实施完成——T059 六门禁全绿，Verified 条件未满足项如实列出：浏览器 Network 证据（T054/T055，US3-01～10 全部待执行）、真实 Linux 硬件加速与资源画像（T058 G1–G6）、双架构镜像实测（T057，Docker Hub 不可达），缺口清单见 evidence.md T060 FR/SC 终验核对）；关联 [004规格](../specs/004-playback-resolver/spec.md)、[计划](../specs/004-playback-resolver/plan.md)。实施授权已生效，验证完成前不标 Verified；不改变ADR-0007目录身份与ADR-0008绑定规则。

## Context

目录之后需要同一授权入口播放IPTV和常见NAS影片；仅支持浏览器原生格式不足。逐请求权限变化必须生效，媒体处理不能阻塞业务事务，NAS资源有界且原文件只读。

## Decision proposal

统一同源会话化网关，原设备会话+hash存储的短时ticket共同鉴权，逐请求校验当前档案、最新策略和资源。主动播放新session；续期复用session/转换，seek和音轨改变以generation失效旧资源。会话、失败事件分离并保留家庭/档案边界。

NAS先直放，再复制编码转封装，再仅转换不兼容轨道；FFmpeg/ffprobe受控子进程，hls.js/原生HLS消费兼容输出。上游HLS由应用网关安全读取并重写全部资源URI，转换进程不直接抓远程资源。输出/字幕同样鉴权，无公开静态缓存。

并发默认1、部署可配置1～8，无队列；硬件优先、软件回退，线程/时限/滚动缓存/磁盘预算及失联回收按research R4/R5。所有探测/spawn在SQLite写事务外，额度预留与CAS在短事务内。首帧30秒、seek15秒；不足实时能力稳定失败，不自动降分辨率。只保证FR-014 1080p SDR矩阵，4K/HDR尽力直放；文字字幕与音轨选择纳入，无字幕烧录。

## Alternatives and consequences

原URL下发泄漏源且绕过后续授权；仅TTL失效与逐请求授权要求冲突；全部转码增加CPU；外部工作服务/队列超出单家庭当前规模；跨用户转换缓存复杂且可能泄漏权限，均不选。引入FFmpeg增加镜像与编译/许可证审查责任，hls.js增加前端依赖；实施时锁版本并记录许可，真实硬件性能不得由仿真替代。

## Migration and acceptance

新增0005及独立共享播放契约，不修改旧迁移。down移除播放状态，身份/目录/EPG/策略不变；手工记录恢复依赖一致备份，活动票不因恢复复活。SC-001～009多层证据、容器双架构、真实硬件/浏览器通过后才能Verified。没有架构例外，Proposed不得作为实施接受依据。
