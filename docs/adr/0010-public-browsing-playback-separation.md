# ADR-0010：公开浏览与播放授权分离

- 状态：Accepted（2026-10-26 维护者随规格005实施指令显式接受；替代关系自此生效，实施与证据见 specs/005 tasks.md/evidence.md）
- 依据：宪章1.2.0原则二/三/四/五；[规格005](../specs/005-pc-browsing-flow/spec.md)、[研究R1/R8](../specs/005-pc-browsing-flow/research.md)。
- 关联：ADR-0002/0003/0006/0007/0008/0009继续作为有效基线，以下替代关系仅在本ADR接受并同步规格后生效。

## Context

既有目录与节目查询要求会话及当前Profile策略放行，详情不可见时不展示播放入口。新目标允许游客浏览全部可用元数据，只在播放时认证选档并执行策略；仅删前端守卫无法满足目标。

## Proposed Decision

1. 公共只读元数据使用`/api/public/*`与部署唯一Household上下文，不依赖匿名客户端声明的身份，不按ProfilePolicy过滤。即便已登录，公共目录范围也不因Profile策略收缩。
2. 可用性、家庭边界、来源禁用检查保留；公开DTO白名单不含个人数据、源地址、路径、凭据、播放票据或源ID。公共响应no-store，不创建访客伪会话。
3. 收藏、历史、位置使用`/api/me/*`和当前可信Profile；管理迁入settings；播放的会话/PIN/最新策略/资源/交付鉴权不放宽。
4. EPG复用手动关联优先、失效不自动回退等规则，批量无策略读取核心与播放授权核心分开。单次日期/频道/时间窗口有上限，查询不触发外部导入。
5. 本决策拟替代规格003中US2、FR/SC关于“观看目录/搜索/计数/详情/节目指南必须按Profile策略隐藏”的部分，以及规格004US3中“不可播放内容的详情不可见/无入口”的展示约束。策略判定算法本身、名单管理、资源可用性、播放404同形、交付约束均保留。
6. 浏览可见不承诺可播放；播放失败使用稳定通用文案，不返回策略明细。

## Alternatives and consequences

不采用游客默认成人Profile、anonymous查询开关、仅前端隐藏与原有授权代码直接删守卫。公开资源目录是用户明确的产品选择，个人隐私与媒体资源交付继续隔离；部署管理员需理解局域网浏览可见范围，但本ADR不新增外网共享功能。

## Migration and rollback

本轮不兼容旧路由和业务库，交付代际见ADR-0012。旧目录契约须显式标为被本功能相应行为替代，不能删除旧验收记录。未接受前旧ADR仍不标Superseded。出现浏览越界或公开凭据，回退匹配镜像与数据目录；不能只切前端恢复身份边界。

## Acceptance and evidence

待维护者接受。必须补游客全目录/EPG、失效cookie、跨家庭、个人数据与凭据零泄漏、匿名播放拒绝、已登录儿童仍可浏览但播放被拒绝的契约/runtime/浏览器证据。研究与OpenAPI类型检查不是运行证据。
