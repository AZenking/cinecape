# ADR-0007：媒体身份、受控导入与原子目录发布

- 状态：Accepted（2026-10-23，随 003 媒体目录与来源进入 Implementing 一并接受；实现须按本 ADR 与 tasks.md 执行，验收以 quickstart 证据为准）
- 日期：2026-10-23
- 关联：[规格 003](../specs/003-media-catalog/spec.md)、[实现方案](../specs/003-media-catalog/plan.md)、ADR-0005/0006。

## Context

阶段 2 的资源适配器仍由夹具提供。接入 IPTV/XMLTV/NAS 后必须保证家庭归属、稳定媒体身份、刷新失败不丢数据，以及 NAS 替换内容不会继承原允许项。magi 的用户能力可复用，但其部署和匹配工作台超出已接受范围。

## Decision proposal

1. 单 Nest 进程和 SQLite 中持久化任务与暂存，受控下载/扫描在写事务外执行；每来源一个活动/待确认任务，全局一个运行任务。
2. MediaItem、MediaSource、PlaybackSource 与来源条目分开；媒体身份独立于播放位置。按已确认 tvg-id/URL 与 NAS 相对路径规则做稳定 upsert，不删除重建或自动跨来源合并。
3. 格式非法整次失败；已有非空 IPTV/NAS 快照遇空结果或缺失 ≥25% 时等待家长确认；发布校验版本/修订/摘要，目录变更与 NAS 分级/名单清理在单事务完成。
4. 真实目录事实由服务端按 Household 装配；列表先授权再分页计数，详情与节目同样授权；管理候选有独立 owner+密码入口。阶段 3 不公开播放 URL、物理路径或媒体下载。
5. 使用有界流式 M3U/XMLTV、sax strict 与 gzip；网络通过已验证 IP 固定连接，每跳重新校验；内网须部署精确许可加家长确认。NAS 只读受授权根，拒绝符号链接与越界。
6. EPG 为独立家庭源，仅保留设置、手动刷新、状态、IPTV 来源级精确关联和当前/下一节目。不迁移工作台、任务队列、请求头、定时器或真实凭据。
7. 新增独立名单写契约并保留等级更新契约，所有策略写入共享版本；NAS 自动清理以最新策略为准，保留禁止项。

## Alternatives and consequences

逐条修改可见目录、删除重建身份、前端过滤或按标题自动合并均不接受。复用 magi 全套队列增加部署和一致性成本；采用本地串行执行器代价是后台吞吐有限，当前有明确队列/解析预算和手动重试。完整文件哈希/重命名识别不在范围；size/mtime 未变替换无法识别。对源地址和敏感查询值的本地保存仍属于私有配置，备份也必须视为敏感数据。

## Migration and rollback

新增 0003 成对迁移及复合外键，不重建阶段 1/2 表；更新就绪和演练清单。down 保留身份/PIN/策略，但移除本阶段目录，遗留名单 ID 不自动清理；up 不恢复原媒体 ID，需使用一致性备份完整恢复。演练在临时库/独立卷，不操作真实家庭实例。新 ADR 在实现前接受，不能以文档生成替代验收。
