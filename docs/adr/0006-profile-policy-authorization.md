# ADR-0006：ProfilePolicy 规则与家长管理边界

- 状态：Accepted（2026-10-23）
- 日期：2026-10-23
- 关联：[规格 002](../specs/002-profile-policy/spec.md)、ADR-0002/0003/0005、宪章原则二/三/五。
- 005 关联标注（2026-10-27）：[ADR-0010](0010-public-browsing-playback-separation.md)/[ADR-0011](0011-main-profile-settings-access.md)/[ADR-0012](0012-profile-resume-fresh-storage.md) 扩展本 ADR 的授权体系（公开浏览不执行 ProfilePolicy 展示过滤但播放授权完整保留；设置 PIN 与选档 PIN 共享持久失败锁定）；**本 ADR 的逐次敏感操作账号密码验证继续有效，未被替代**。
- 2026-10-23 维护者接受本 ADR 全部决策（含未评级默认值、名单覆盖语义、成人无 PIN 切换保护与 5 次/5 分钟锁定参数）；接受同时已同步领域模型 §6 与 002 设计文档。

## Context

领域模型 §3.5 有策略字段但无等级默认值及管理再验证。阶段 1 owner 会话可承载儿童观看；创建档案、清 PIN 仅依赖 owner，成人无 PIN 可直接选择。仅新增策略表不能阻止儿童通过上述入口扩大权限。媒体目录和 Resolver 尚未交付。

## Proposed Decision

1. 内部 contentLevel/maxContentLevel 使用 0～18 年龄阈值；成人默认 18 且允许未评级，儿童默认 12 且不允许未评级；名单默认空。没有可靠映射的外部分级按未评级，不声称满足任何地区分级标准。
2. 家庭资源边界与禁用先校验；媒体禁止优先；儿童频道白名单为必要条件；未评级独立按 allowUnrated；媒体允许名单仅覆盖已评级的普通等级上限。成人类型不产生授权豁免。
3. owner 管理写入（含既有 Profile 创建/编辑/PIN 清除）每次重新验证账号密码；有任一儿童档案时，选择未设 PIN 成人也须验证。已有 PIN 选择流程继续使用 PIN，一次性授予不变。
4. 家长密码错误按账号持久化计数，5 次锁 5 分钟；新会话/重启不能重置；不引入长期家长管理标记。升级清空儿童家庭中未设 PIN 成人的活动上下文。
5. 一 Profile 一策略，显式 Household 复合外键，JSON 名单、版本比较整体保存。运行时缺失策略拒绝；只在创建和迁移生成默认。
6. 策略核心与会话/资源查询分离。阶段 2 无真实媒体入口，不提供客户端上传媒体事实的授权接口；阶段 3/4 必须复用服务端核心并分别补验收。
7. 本阶段管理界面只编辑等级与未评级，名单只读等待媒体目录；内部存储和规则以可信夹具验收。媒体资源归属验证接入后才能开放名单编辑。
8. 对 homeMediaDomainModel.md §6 的“:profileId 只用于选择/解锁”作显式补充提案：已存在的 owner 档案管理及新增策略管理也可指定目标，但仅作经归属校验的管理目标，不得作为内容授权的观看者来源。接受时同步领域文档，不能静默改变 Frozen 规范。

## Alternatives and consequences

仅 owner 校验无法区分拿设备的家长与儿童；只在前端隐藏无效。强制全部成人立即设置 PIN 会引入用户凭据迁移，改为无 PIN 成人切换时密码验证。每次写入重验交互较重，但避免新建可被共用的长期授权票据。维护者已于 2026-10-23 确认 0～18 年龄阈值、儿童默认 12、成人默认 18，以及管理操作重验主账号密码。频道允许仍不保证节目安全，未评级需家长显式放行。

## Migration and rollback

新增 0002 迁移（本轮不编写 SQL）回填现有档案策略，增加账号验证状态；只清必要活动上下文，保留身份、PIN 与会话令牌。down 删除新增策略/验证数据，阶段 1 业务数据保留。恢复自定义策略需要回滚前备份；旧镜像不执行策略，不能称为安全等价降级。接受本文后同步领域模型、001 契约和 002 设计，历史 ADR 保留。

2026-10-23 维护者进一步接受完整 ADR：未评级默认值（成人允许、儿童禁止）、名单覆盖语义（允许名单仅覆盖已评级等级上限）、成人无 PIN 切换保护、失败锁定参数（连续 5 次锁 5 分钟）及迁移与接口方案。接受变更与规格 002、领域模型 §6 补充同步完成；实现按 tasks.md 进入，规格状态流转 Accepted → Implementing。
