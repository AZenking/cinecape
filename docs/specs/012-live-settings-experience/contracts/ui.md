# UI 契约：交互与焦点（012-live-settings-experience）

**Date**: 2026-11-01 | **Status**: Proposed（随规格接受生效）
**约束对象**: apps/web 全部直播/EPG/设置呈现层。视觉值一律消费 HeroUI 语义 token 与 [DESIGN.md](../../../DESIGN.md)，本契约只定义**行为**，不定值。

## §1 统一播放链路（FR-005–FR-009）

1. 唯一发起面：所有直播播放入口（NowHero/NowSection/NextSection/GroupSections 卡片主按钮、EPG 频道观看按钮、首页直播入口）必须经 `usePlayAction` 发起；严禁入口自行调 `/playback/*` 或直接挂流。
2. 游客/未选档点击播放：进入统一登录→选档链路（ActionCoordinator 全局 Modal，至多一层）；入口页面保持挂载；播放意图在内存暂存，完成选档后回到 `returnTo`（白名单内）并继续授权。
3. 授权拒绝：在入口上下文内展示用户可理解原因 + 重试/返回详情；不得导航离开原页面、不得暴露内部错误码（诊断详情按需展开场景仅限设置/任务面）。
4. 登录期间目标节目结束：授权重解析为该频道此刻内容——入口按钮与意图保持「频道」语义，不锁定「具体节目」。
5. 收藏按钮：独立于播放；点击仅执行收藏（Profile 级）；游客点收藏显示登录引导、不产生任何请求与部分写入；收藏成功为行内反馈，不得触发播放。
6. 未来节目（status=upcoming）与已结束（ended）：卡片/面板不得渲染可用「播放」主操作；upcoming 主操作=查看详情/节目单，ended=查看详情。

## §2 节目详情面板（FR-013）

1. 单一组件：直播首页三区（Now/Next/Groups）与 EPG 节目单必须挂载同一详情面板组件（research R2）；允许宿主差异（触发位置、宽度档位），禁止内容/行为分叉。
2. 呈现：抽屉或浮层，底层页面保持可见；打开时焦点入面板，Escape/关闭按钮/遮罩点击关闭并恢复触发元素焦点。
3. 内容六要素：频道名称+标识、节目标题+简介、起止时间+时长（家庭时区标注）、状态（正在直播/即将开始/已结束/暂无节目数据）、主操作（仅 now：「播放当前频道」）、次操作（收藏频道、查看节目单）。
4. 面板打开期间 30s 刷新：内容可更新，面板不得关闭、焦点不得跳出、滚动位置不得重置。
5. 无节目数据：保留频道身份与「暂无节目单」；频道可用时主操作仍可为「播放当前频道」。

## §3 EPG 节目单（FR-015–FR-019）

1. 首次进入：定位当前时间附近，当前节目与后续排期同屏可见；显示时区说明（家庭时区）。
2. 手动浏览过去/未来：任何自动刷新不得拉回现在或重置窗口；仅用户显式操作（日期切换/回到现在）改变日期。
3. 「回到现在」：恢复今天+当前时间窗口；频道/分类筛选、视图模式保持不变。
4. 节目块点击：打开详情面板（§2），不直接播放；频道观看按钮播放该频道当前直播。
5. 状态恢复：date/from/channelPage/pageSize/view 写 URL（见 [url-state.md](url-state.md)）；刷新/直链完整恢复；滚动位置为会话内状态，刷新后回默认位置（可接受）。

## §4 播放器（FR-020–FR-023）

1. 能力清单（直播）：当前频道与节目名、直播状态与进度、切换频道、字幕/音轨/清晰度当前控制、退出、失败原因+重试。
2. 退出：恢复来源页面 URL/筛选/滚动/详情面板状态/触发焦点；Escape、返回按钮、遮罩关闭均回触发入口，不回首页。
3. 切换 Profile：旧授权终止+旧票据不可用后，新 Profile 重新授权才继续播放（沿用 005/010 身份撤销收口）。
4. 播放设置浮层：打开/关闭不中断播放；浮层内不提供跳转完整设置页入口；浮层行为遵循 009 非阻塞框架。
5. 播放失败重试：复用同一意图/会话语义，不产生并行第二会话。

## §5 设置布局与交互（FR-024–FR-029）

1. 左侧分组导航：个人偏好 / 家庭管理 / 系统三组；组头显示作用范围标注（家庭管理组标注「需要管理授权」）；个人偏好组按澄清 Q1「分组先行」——无确有支持的项则整组不渲染，禁止空模块。
2. 模块路由不变：`/settings/{key}` 七条路由与默认 account 保持；分组仅改变菜单组织与视觉，不改地址语义。
3. 解锁门：沿用 settings-unlock-gate 既有判定（本规格不改验证逻辑；其规则归属 ADR-0011/011 替代关系）；锁定态下家庭管理区域显示锁定说明，不渲染管理数据。
4. 交互规则：开关/单选即时生效、无全页保存按钮；复杂表单局部保存（保存按钮仅在当前编辑区域）；退出登录/删除 Profile/撤销会话/重置设置二次确认；模块加载失败仅影响该模块（左侧导航可用+重试入口）；URL 保留当前分类，刷新打开原模块。
5. 播放器控制不进设置页：设置仅存默认值语义；当前值控制在播放器浮层（§4.4）。

## §6 焦点与键盘（FR-030–FR-033）

1. 全部可交互元素有可见焦点态（`--hmp-focus-ring-*` token）；状态表达不得仅靠颜色（直播中/选中/错误/禁用须有文字/图标/形状之一）。
2. 卡片与列表项：方向键移动、Enter/Space 激活；焦点顺序按内容层级（Now Hero → 正在直播 → 接下来 → 分组 → 节目单 → 详情 → 播放 → 返回原焦点）。
3. 弹层（详情面板/登录选档/播放设置）：至多一层；进入捕获焦点、关闭恢复触发焦点；验证/错误聚焦不清空其他编辑。
4. 响应式：窄屏侧栏/设置菜单折叠为列表；200% 缩放与低高度窗口下保存/取消/播放入口可达；动效遵守减少动态偏好。
