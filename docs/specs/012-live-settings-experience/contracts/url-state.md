# URL 状态契约：可恢复状态（012-live-settings-experience）

**Date**: 2026-11-01 | **Status**: Proposed（随规格接受生效）
**原则**: 语义状态进 URL（可分享/可直链/刷新恢复）；视口状态（滚动/焦点）留应用会话内存（澄清 Q2 口径：不新增浏览器存储面）。

## §1 /live/guide（FR-018，既有 GuidePage 契约的冻结与补齐）

| 参数 | 语义 | 取值/缺省 | 状态 |
| --- | --- | --- | --- |
| `date` | 节目单日（家庭时区日历日） | `YYYY-MM-DD`；缺省=今天 | 既有，冻结 |
| `from` / `to` | 时间窗口（当日 UTC 边界语义） | 缺省=当前时间附近窗口 | 既有，冻结 |
| `channelPage` / `pageSize` | 频道分页 | 正整数；非法回落缺省 | 既有，冻结 |
| `view` | 视图模式（墙/列表） | 枚举；非法回落缺省 | 既有，冻结 |
| 频道/分类筛选 | 筛选集合 | 缺省=全部 | 既有项，核对；「回到现在」不得清除（FR-016） |

规则：
1. 用户显式变更（日期切换、翻页、切换视图、筛选）→ `setSearchParams`（replace 语义沿用现实现），不可伪造值崩溃。
2. 刷新/直链：按 URL 完整恢复语义状态；非法/未知值静默回落缺省。
3. 滚动位置/焦点：**不进 URL**；会话内保留（详情返回恢复），页面刷新后回缺省位置（可接受，quickstart 声明）。
4. 「回到现在」动作：改写 date/from 至今天+当前窗口，保留其余参数（尤其筛选）。

## §2 /live（直播首页）

| 状态 | 载体 | 说明 |
| --- | --- | --- |
| 分区/入口来源 | 内存（entry 上下文） | 详情返回恢复依据（FR-013） |
| 分组浏览位置 | 会话内存 | 可选进 URL（如 `group=`）；若既有实现已有则冻结，无则不强加 |
| 滚动/焦点 | 会话内存 | 刷新回顶（可接受） |

规则：直播首页**不强制**新增 URL 参数；已有参数（若存在）冻结语义。返回恢复靠「入口上下文 + 会话内存」，不靠全量 URL 复刻。

## §3 /settings/{key}（FR-028，既有 T086 契约）

| 项 | 语义 | 规则 |
| --- | --- | --- |
| `{key}` 路径段 | 当前模块（account/profiles/policy/sources/epg/devices/general） | 七条路由不变；未知子路径回落默认 account（既有语义） |
| 分组 | 菜单组织（personal/household/system） | **不进 URL**——分组是导航视觉，模块 key 才是地址事实 |
| 模块内部状态 | 各模块既有查询参数（若有） | 冻结既有语义，本规格不改模块内部 |

规则：刷新后按 URL 打开原模块（FR-028）；分组渲染只依赖注册表元数据（data-model §4）。

## §4 跨页返回恢复矩阵

| 触发路径 | 恢复内容 | 机制 |
| --- | --- | --- |
| 详情面板 → 播放 → 退出 | /live 或 /live/guide 的 URL 状态 + 滚动 + 详情面板状态 + 焦点 | URL + 会话内存（FR-021） |
| 直播/EPG → 登录/选档（取消） | 原页面 + 原面板/弹层状态 + 焦点 | ActionCoordinator returnTo + 页面保持挂载 |
| 直播/EPG → 登录/选档（完成） | 原目标 + 继续授权 | returnTo（白名单） |
| 设置 → Profile 菜单返回 | 原分类模块 + 焦点 | URL key + 焦点恢复（FR-029） |
| 任何页面刷新 | URL 语义状态；内存态（意图/滚动/焦点）按缺省 | §1–§3 |

## §5 禁止事项

1. 禁止把滚动像素值、时间戳视口、临时弹层开关写入 URL（噪音与历史污染）。
2. 禁止以 URL 承载身份/意图（意图内存态、身份在 httpOnly Cookie 会话——session-provider 既有约束）。
3. 禁止为「可恢复」而在 localStorage/sessionStorage 新增键（澄清 Q2；个人缓存仅限内存 query 缓存且随身份 purge）。
