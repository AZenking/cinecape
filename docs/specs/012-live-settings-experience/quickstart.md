# Quickstart: 012-live-settings-experience 验证指南

**Date**: 2026-11-01 | **Spec**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)
**性质**: 端到端验证/运行指南。实现细节属 tasks.md 与实施阶段；本文件不含实现代码。

## 前置条件

- 本地依赖已安装（`pnpm install` 已完成 postinstall：gen:types + shared build）。
- 服务端可启动（`pnpm --filter @hmp/server dev`），数据库为可重建的本地开发库（本规格零迁移，任意既有迁移状态即可）。
- 前端开发服（`pnpm --filter @hmp/web dev`）与测试基座：
  - web 单测：`pnpm --filter @hmp/web test`
  - e2e：`pnpm --filter @hmp/web test:e2e`
  - 契约/单测基线：`pnpm --filter @hmp/server test:unit` / `test:contract`（预期零新增，保持既有全绿）
  - 静态门：`pnpm lint` && `pnpm typecheck`
- 一个游客浏览器档案（无登录态）+ 一个已登录、已选主档案的会话，用于场景切换。

## 场景 1：游客浏览与统一播放链路（SC-001/SC-006，对应 contracts/ui.md §1）

1. 以无痕/游客档案打开 `/`、`/live`、`/live/guide` 与任一节目详情面板——全部可浏览，无阻断式登录页（FR-004）。
2. 打开浏览器开发者工具 Network 面板，过滤 `playback` 与个人接口（`/me/`）。
3. 在直播首页 Now Hero 点击「播放当前频道」：
   - **预期**：出现统一登录弹层（至多一层），页面保持在 `/live`，Network 中**零** `playback/*` 与 `/me/*` 请求（授权前零媒体流）。
   - 完成登录 → 选档（必要时 PIN）→ **预期**：回到 `/live` 原位置并继续授权，随后才出现 playback 请求并进入播放。
4. 重复步骤 3 于：EPG 频道观看按钮、接下来/分组卡片主按钮、首页直播入口——三入口行为一致（SC-002 链路一致率 100%）。
5. 取消登录弹层——**预期**：无任何写入、无播放发起、焦点回到触发按钮。
6. 刷新页面后重新点击播放——**预期**：正常重新进入登录链路（意图丢失可接受，FR-006/Q2）。

## 场景 2：收藏与未来节目（FR-011，ui.md §1.5/§1.6）

1. 游客点击卡片收藏——**预期**：登录引导出现，零请求、零部分写入。
2. 已选档点击收藏——**预期**：仅收藏频道（`/me/favorites/channels` 写入），行内反馈，**不触发播放**。
3. 找一个「即将开始」节目卡与一个已结束节目——**预期**：无可用「播放」主操作；即将开始显示开播时间，主操作为查看详情/节目单。

## 场景 3：节目详情面板统一与安静刷新（FR-013/FR-014，SC-002/SC-003，ui.md §2）

1. 分别从 正在直播、接下来、EPG 节目单 打开节目详情——**预期**：同一类面板（结构/内容六要素一致），底层页面保持可见。
2. 面板打开状态下停留 ≥10 分钟（或临时把刷新间隔调短**仅限本地调试**，验收数值仍按 30s 契约）：
   - **预期**：焦点不丢、面板不关、底层分页/筛选不重置（连续观察法，SC-003 零打断）。
3. 按 Escape 关闭面板——**预期**：面板关闭且焦点恢复到触发元素。

## 场景 4：EPG 状态保留与「回到现在」（FR-015–FR-019，SC-004，url-state.md §1）

1. 首次进入 `/live/guide`——**预期**：定位当前时间附近，显示时区说明（家庭时区）。
2. 手动浏览到明天/过去日期并切换筛选与视图——**预期**：URL 参数同步（date/view/筛选…）；把该 URL 复制到新标签打开——**预期**：语义状态完整恢复。
3. 点击「回到现在」——**预期**：回到今天+当前时间窗口，**筛选与视图保持不变**。
4. 停留 30 秒以上等待自动刷新——**预期**：浏览位置不被拉回现在。
5. 刷新页面——**预期**：URL 语义状态恢复；滚动位置回缺省（可接受，契约声明）。

## 场景 5：播放连续性（FR-020–FR-023，SC-005，ui.md §4）

1. 从 `/live/guide` 进入播放后退出——**预期**：回到 guide 原 URL 状态、滚动与焦点恢复，不回首页。
2. 播放中经身份菜单切换 Profile——**预期**：旧播放终止且旧票据不可用（负向：旧票据重放被拒），新 Profile 授权后继续。
3. 播放中打开播放设置浮层再关闭——**预期**：播放不中断；浮层内无「打开完整设置」入口。
4. （可选/联调）断开来源模拟播放失败——**预期**：原因说明+重试，重试不产生并行会话。

## 场景 6：设置分组与交互（FR-024–FR-029，SC-007，ui.md §5）

1. 从身份菜单进入设置——**预期**：左侧三组（个人偏好/家庭管理/系统）；个人偏好组**不出现空模块**（Q1：无支持项则整组隐藏）；家庭管理组标注「需要管理授权」。
2. 访问 `/settings/epg` 后刷新——**预期**：仍打开 EPG 模块（URL 分类保留）。
3. 制造某模块加载失败（如断网后重试该模块）——**预期**：仅该模块报错并可重试，左侧导航可用。
4. 触发退出登录/撤销会话等危险操作——**预期**：二次确认与后果说明；确认行为按届时已接受的设置访问规则执行（验证规则本身归 011，不在本场景判定）。
5. 窄窗（拖窄浏览器）/200% 缩放——**预期**：菜单折叠可用，保存/取消/返回不被遮挡。

## 场景 7：键盘全流程走查（FR-030–FR-033，SC-008/SC-009）

仅用键盘完成：主导航 → 直播首页（方向键移动卡片、Enter 打开详情）→ 播放/取消 → Escape 返回原焦点 → EPG 浏览与筛选 → 设置分组导航。全程：
- 每个可交互元素有可见焦点环；
- 状态（直播中/选中/错误/禁用）不仅靠颜色区分；
- 减少动态偏好开启后动效最小化。

**记录**：走查结果与截图记入 `evidence/`（任务阶段建文件），负向断言（零媒体流请求、零个人数据读取）以 Network 截图或 e2e 断言输出为准。

## 自动化回归基线

```bash
pnpm lint && pnpm typecheck                # 静态门
pnpm --filter @hmp/web test                # web vitest（含新增组件/e2e 前置单测）
pnpm --filter @hmp/web test:e2e            # Playwright e2e（场景 1/3/4/5 自动化面）
pnpm --filter @hmp/server test:unit && pnpm --filter @hmp/server test:contract
# 预期：server 基线零新增零破坏（contracts/api-reuse.md §4）
```

## 失败处理

任一场景失败：按 [contracts/ui.md](contracts/ui.md) §7 的断言映射定位规格条目；涉及服务端缺口走 [api-reuse.md](api-reuse.md) §3 升级通道；涉及验证规则（设置解锁）的失败不属于本规格验收范围（归 011）。
