### 1.2 关键交互契约
1. **顶部 Hero 区域**：
   - 采用 16:9 高度自适应视口容器，默认播放首选频道；
   - 带有音量开关（默认静音免打扰）；点击正中或 `[ ▶ 全屏播放 ]` 进入大屏模式；
2. **分流入口**：
   - `Live` 行尾的 `[全部正在直播 >]`：链接到 `/live/guide`（Screen 3 EPG 节目单墙）；
   - 各分类行尾的 `[全部XX频道 >]`：链接到 `/live/channels?group=:key`（Screen 2 分类网格）；
3. **卡片 Hover 态**：
   - 卡片正中央浮现 `bg-accent/80 text-accent-foreground` 的 `▶` 按钮，点击即发起该频道直接播放；
   - 点击卡片文本信息区域，导航至 `/live/watch/:id`。

```text
└────────────────────────────────────────────────────────────────────────┘
```

### 2.2 关键交互契约
1. **分类 Tabs 联动**：
   - 接收 URL 参数 `?group=movie`，分类 Tabs 自动高亮对应的“电影”分类，无需手动二次点击；
   - 切换分类 Tab，平滑过滤网格，URL 自动保持同步；
2. **多列响应式网格**：
   - 大屏（`>= 1440px`）：4~5 列；中屏（`1024px ~ 1439px`）：3~4 列；窄屏（`768px ~ 1023px`）：2 列；
   - 频道卡片直出播放与收藏动作，悬停浮现强调色播放按钮。

### 4.2 关键交互契约
1. **进入即起播**：
   - 页面加载时自动调起 `POST /playback/resolve`，播放器就绪即播，无需任何二次点击；
2. **右侧伴随面板**：
   - 展示当前节目详细进度条（计算百分比）、演职员与剧情简介、收藏按钮；
   - 清晰呈现“即将播放 (Next)”条目与开播时间；
3. **底部同类型直播换台 (`sam type live`)**：
   - 抓取相同 `group_title` 的其他当前在线频道；
   - 点击任意卡片，播放器在**当前页面就地平滑换流**，右侧节目简介即时联动更新，浏览器 URL 经 `replaceState` 同步更新为 `/live/watch/:newId`。
