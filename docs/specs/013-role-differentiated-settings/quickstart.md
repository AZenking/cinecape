# Quickstart & Verification Guide: 角色差异化设置体系

**Feature**: `013-role-differentiated-settings`
**Date**: 2026-11-02

本指南提供在本地开发与测试环境中验证“角色差异化设置体系”的快速走查场景。

---

## 1. 运行前提与测试准备

确保本地依赖安装完成，且具备至少两个测试 Profile：
- **管理员 Profile (Main)**：`isMain: true`，设有 6 位 PIN 码（如 `123456`）。
- **普通成员 Profile (Member)**：`isMain: false`。

```bash
# 运行单元与契约测试
pnpm test
```

---

## 2. 验证场景一：普通成员的纯净个人偏好视图

1. **步骤**：
   - 在前端点击右上角头像，切换至普通成员 Profile。
   - 点击导航栏中的“设置”入口。
2. **预期验证点**：
   - 侧栏菜单仅出现【个人设置】分组（包含：播放体验、界面外观、我的档案）。
   - 侧栏中**完全没有**媒体来源、电视与节目单、内容策略、设备管理等项。
   - 侧栏底部**没有任何**“切换管理员”按钮或锁提示。
   - 页面没有任何密码或 PIN 码弹窗阻拦。
   - 修改“默认字幕”并保存，页面给出成功反馈，网络请求命中 `/api/profile/preferences`。

---

## 3. 验证场景二：深链接越权拦截

1. **步骤**：
   - 保持普通成员 Profile 会话。
   - 在浏览器地址栏手动输入受保护的管理路由：`http://localhost:5173/settings/sources` 并回车。
2. **预期验证点**：
   - 前端 `AdminRouteGuard` 拦截请求，页面自动平滑重定向回 `/settings/playback`。
   - 弹出轻提示：“该配置项需要主管理员权限”。
   - 控制台未泄漏任何源管理的数据接口请求。

---

## 4. 验证场景三：管理员一次验 PIN 畅行全场

1. **步骤**：
   - 点击右上角头像菜单，选择管理员 Profile。
   - 系统弹出标准 PIN 码输入浮层，输入 `123456` 完成选档。
   - 切换成功后，点击进入设置。
2. **预期验证点**：
   - 侧栏立即呈现全量分组（个人设置、家庭管理、系统与安全）。
   - 进入【媒体来源】，添加一个测试 M3U 源，点击保存，**全程零弹窗二次索要 PIN 或密码**，数据直接持久化成功。
   - 进入【电视与节目单】、【内容策略】进行配置，均可连续顺畅操作。

---

## 5. 验证场景四：高危不可逆操作的单次确认底线

1. **步骤**：
   - 处于管理员设置下，进入【账号与安全】模块。
   - 尝试执行“修改管理员登录密码”。
2. **预期验证点**：
   - 系统要求输入当前旧密码进行单次安全校验。
   - 输错旧密码返回明确错误提示；输入正确密码后更新成功并撤销其他活动会话。
