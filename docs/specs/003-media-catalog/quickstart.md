# Quickstart: 003 计划验证指南

状态：计划，以下均待实施后执行；本轮没有运行新增 API、迁移、浏览器或容器验收，不预填测试通过。

## 先决条件

接受 ADR-0007，完成 tasks/analyze 和实现。Node 24、pnpm@11.28.5、独立临时 DATA_DIR、独立端口及浏览器域名；NAS 只读临时根、受控 M3U/XMLTV 服务（HTTP/gzip/重定向/失败夹具）、ARM64/AMD64 容器运行环境。夹具局域网地址仅在测试专用精确许可内启用，不禁用生产 SSRF 校验；不读取 magi 的真实数据或凭据。

在仓库根执行现有命令，DATA_DIR 必须指向新建临时目录：

```bash
pnpm install --frozen-lockfile
pnpm gen:types
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

独立库迁移/运行示例（先自行创建并核对该临时目录，不能改成用户数据目录）：

```bash
DATA_DIR=/tmp/hmp-003-validation pnpm migration:up
DATA_DIR=/tmp/hmp-003-validation pnpm migration:drill
DATA_DIR=/tmp/hmp-003-validation PORT=3183 pnpm --filter @hmp/server start
pnpm test:runtime
```

test:runtime 本身使用独立临时库；实施时需扩展阶段 3 场景，不能仅凭现有阶段 2 PASS 验收。本指南不包含实现代码/SQL；结构和契约分别见 [data-model.md](data-model.md)、[contracts/api.md](contracts/api.md)。

## A 来源/身份/刷新（SC-001/002）

先验证空库迁移 0003 后初始化家庭，唯一 catalog_state=1，首个来源创建可推进修订。US1 只验来源 API、任务和临时库；需 /media 的禁用可见性断言在 US2 完成后执行，完整 EPG 设置/节目展示在 US4 执行。

1. 全新实例初始化并创建档案；家长验证添加 IPTV、EPG、NAS 三来源，分别刷新后核对数量、状态和重复刷新身份不变。
2. IPTV tvg-id 相同地址改变保持 ID 与人工分级；无 tvg-id 地址改变产生新 ID，旧不可用、名单不转移；重复标识、缺 URL、部分非法条目整次失败，旧快照不变。
3. NAS 同名不同路径分别建内容；改名/移动视为新内容；断挂载/拒绝权限不能作为成功空目录。符号链接、..、根外目录、非授权 rootKey 拒绝，不写入原文件。
4. 构造恰好 25% 缺失、低于 25%、空结果和首次导入空结果，核对确认门槛；待确认时仍读旧目录。确认密码错误/版本旧/过期/来源变更/目录修改/NAS 暂存后再变化均不发布。
5. 同 operationKey 重试不重跑；同来源并发或待确认未处置时第二任务拒绝；全局最多一个运行、队列满 429。重启中断可见，旧目录保留，用户手动重试。

## B 真实目录与名单（SC-003/004/007）

1. 成人/儿童、允许/禁止交集、超限、未评级、儿童频道门槛矩阵，分别验证列表、标题搜索、翻页计数、详情、当前/下一节目；隐藏内容不出现在 total 或关联数据。
2. 无 activeProfile、停用档案、损坏策略、跨家庭、过期/撤销会话、伪造 householdId/profileId/rating/role 均拒绝；直接访问已知被禁 ID 与不存在返回同形。
3. owner 角色未做家长验证不能查询候选或保存；通过后可查自己观看策略隐藏的候选，跨家庭仍不可见；响应、错误和浏览器存储没有路径/地址/密码。
4. 三名单整体保存、重复去重、1000/1001 边界、非频道写频道名单、未知/跨家庭 ID、并发旧 version 均有断言。现有等级保存不改变名单。
5. 两设备查询，策略变更后另一设备下一请求生效；切换档案时旧在途请求不得覆盖新档案目录。

6. 在家长已验证候选/允许的详情页编辑标题、非频道类型、分级与恢复未评级，验证密码错误/非法输入/409 保留非敏感表单且清空密码；成功重载持久、普通刷新不覆盖人工标题/类型，分级保存后目录权限更新。浏览器证据独立于 Node HTTP 冒烟。

## C NAS 替换原子性（SC-009）

为同一路径设置人工分级并被多个 Profile 允许/禁止。改大小或 mtime 后刷新：ID 保留、level=null、全部允许项清除、禁止项保留；每个受影响档案版本增加。旧表单保存 409；同大小/mtime 未变则保留配置。旧路径消失后以变化的文件重现也触发清理。注入发布事务失败，事实/分级/策略/任务不得部分成功；损坏策略不能被跳过。明确 allowUnrated=true 的档案仍可访问未评级内容，不把清名单误称全员禁止。

## D EPG 设置与节目（SC-008）

真实浏览器新建/编辑名称地址启用，省略地址保留原密钥，不允许掩码作为地址。手动刷新显示运行与完成、频道/节目数量、最近成功；首次刷新即导入，无重复检查/导入入口。IPTV 选同家庭一 EPG，按 tvg-id 精确匹配；同 EPG 可复用，未关联/禁用/未知标识/冲突均暂无节目。跨日及显式时区、当前结束边界、下一节目、已过期数据有测试。失败保留旧指南，重启 running→interrupted，再手动重试成功。

## E 导入安全与预算

受控夹具测试 loopback、link-local、元数据、IPv4-mapped IPv6、DNS 多地址混入非法地址、DNS 重绑定、重定向到禁止目标及精确 LAN 许可；每跳固定已验证 IP。XML DOCTYPE/未知实体/过深嵌套/gzip 扩张/字节或条目超限/超时均失败，旧数据不变，错误不输出原 URL 或 XML。各类源参数和非 owner 直调也有负向用例。

## F 升级/回滚/恢复（SC-006）

从阶段 2 已提交代码和临时库建立成人/儿童/PIN/自定义策略，应用 0003；校验无身份/PIN/策略值变化。导入目录并设置名单，再停服备份，独立副本执行 0003 down/up；确认原身份策略保留，目录不能被误称已恢复。恢复回滚前备份核对旧 media ID、节目、策略 version、integrity_check 和 foreign_key_check。旧版本不执行新媒体授权，不能作为安全等价线上降级；用户实例不运行 down/drill。

## G 性能与容器（SC-005）

10000 内容数据集，记录机器/容器限制，真实浏览器 20 次搜索翻页至少 19 次 ≤2s；同时刷新时仍浏览旧快照。记录实际内存，不将空闲样本当峰值。ARM64 原生、AMD64 若仿真须注明，非 root、只读挂载、独立卷、自动迁移、SPA 与 healthz、重启持久化、缺新表/迁移 503 全验证。所有命令绑定专用端口和卷，不复用用户 hmp-data。

## H EPG 手动匹配增补（SC-010，2026-10-25 已执行；证据见 evidence.md「手动 EPG 增补证据（US5，SC-010）」节）

1. 从已有0003数据与回滚前备份开始，0004升级验证原目录/PIN/策略不变、无绑定仍自动；down/up只恢复自动，不保留手动；实际恢复备份才核对原绑定和版本。全部在独立临时库/容器卷。
2. 用两个不同频道ID构造自动未匹配；家长验证后选择同家庭EPG来源，按名称/ID搜索分页、看当前/下一节目、保存锁定。可选择不同于IPTV默认的另一EPG。普通儿童/无档案/被禁止频道仍不能通过节目端点绕过策略。
3. IPTV/EPG刷新、服务重启、改默认EPG后配置保留。目标消失/冲突/禁用时invalid且current/next=null，不使用默认EPG；恢复同ID后valid。目标存在但节目已过期仅显示暂无节目，不能误称绑定失效。
4. 家长解除后auto恢复来源级精确匹配；测试version0→1→2→3与两个并发保存、解除后旧version0请求、候选查询后EPG generation改变。全部旧请求409且原配置不变；失败注入证明绑定与catalog revision原子提交。
5. 非owner、缺/错误密码、5次锁定、撤销/过期会话、跨家庭媒体/来源/候选、非频道、禁用来源新绑定、冲突候选均拒绝；候选/普通DTO/日志无源位置/凭据。家长候选可管理观看策略隐藏频道，但普通详情仍404。
6. 真实浏览器独立记录详情和家长候选入口、来源切换清选择、搜索预览、保存/解除、刷新持久、失效提示、409重载、键盘操作及密码清除。Network与真实服务响应配对，HTTP脚本不替代浏览器。ARM64/AMD64再构建验证0004与必需列就绪检查；记录实际执行架构。
7. 全量现有命令重新运行，新增结果写到 evidence.md 新节；旧402/128等数字仅历史。SC-010与四条增补需求全部有对应层级证据后才验收本扩展。
