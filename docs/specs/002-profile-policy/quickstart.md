## 前置条件与数据隔离

Node 24、锁定 pnpm、依赖已安装；规格和 ADR 已 Accepted，实现已完成。新建独立临时 DATA_DIR，Web/API 使用独立端口、浏览器独立域名。不得使用当前用户家庭实例或默认 Docker 卷。迁移命令继承显式临时 DATA_DIR；先核对 env 配置加载不会覆盖它。所有 drill/down 只在此目录执行。

## 自动化门禁

依次执行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm test:runtime`。既有 65 用例是回归基线；新增用例数量按实际执行记录，不预填成功。

新增矩阵必须覆盖：判定表每分支、禁止/允许交集、未评级×允许名单、儿童频道×等级×未评级、空名单、边界 0/18、非法等级、缺失/损坏策略、跨家庭事实、无/停用 activeProfile。服务端集成测试用生产授权服务+真实 DB+可信资源夹具，不用客户端上传事实代替。

## 真实 HTTP 与浏览器

1. 新初始化并创建成人/儿童档案，检查默认策略和原子创建；管理界面刷新后配置一致。
2. 在 owner 会话选择儿童。尝试直接保存策略、建成人、清除 PIN、选择无 PIN 成人：无家长验证全部拒绝。正确密码允许；已设 PIN 成人仍需原 PIN 解锁。
3. 篡改 localStorage、URL/body 的 profileId/householdId/role/contentLevel，不得扩大权限；非 owner、过期/撤销会话拒绝。
4. 错误密码 5 次，换另一会话继续仍锁定；重启后锁定保留；锁定中正确密码也拒绝；测试时钟到期后可重新验证。
5. 两会话读取相同 version，第一会话保存成功，第二保存旧版本应 409 且表单保留。下一次授权立即采用最新策略，不靠刷新。
6. 验证名单编辑暂未启用、等级/未评级提示明确；保存失败保留表单；不在浏览器存储、响应和日志泄漏密码。
7. 网络面板留存请求状态与脱敏响应；不能以 mock API 代替真实后端主流程。

## 升级、回滚、恢复

使用阶段 1 镜像/迁移和临时库建立 adult（有/无 PIN）、child、disabled Profile、活动会话；升级执行 0002。核对一档案一策略、归属、原身份/PIN 保留、无 PIN 成人活动上下文已清空并需重选验证。修改策略，重启验证保留。

离线在临时副本执行 0002 down→up，确认阶段 1 数据保留且策略恢复默认；恢复回滚前备份，确认原自定义策略与 integrity_check。对真实用户库不执行 drill。降级版本没有新策略保护，不允许将其称为无风险线上回滚。
