**Related ADRs**: 已接受 ADR-0002、0003、0004、0005；[ADR-0006](../../adr/0006-profile-policy-authorization.md) 已于 2026-10-23 随本规格一并接受。

## User Scenarios & Testing

### User Story 1 - 为观看者配置内容边界 (Priority: P1)

主账号可为每个档案设置最高内容等级、未评级策略、媒体允许/禁止名单、频道允许名单，设置重启后保留。

**Why this priority**: 在接入媒体前建立统一规则。
**Independent Test**: 创建成人和儿童档案、读取默认策略、修改并刷新/重启，配置完整保留且另一档案不变。

**Acceptance Scenarios**:

1. **Given** 新建成人/儿童档案，**When** 首次查看策略，**Then** 各有且仅有一份对应默认策略。
2. **Given** 已有阶段 1 的档案，**When** 升级，**Then** 为全部档案（含已停用）补齐策略，姓名、PIN、归属不改变。
3. **Given** 主账号通过家长验证，**When** 保存策略，**Then** 配置整体生效；非法值或保存冲突不能产生部分写入。
4. **Given** 过期、被撤销或非主账号会话，**When** 修改策略，**Then** 拒绝且所有策略不变。

### User Story 2 - 一致判定允许或禁止 (Priority: P1)

同一观看者、媒体事实和策略必须得到一致结果，成人类型与账号管理身份均不能跳过判定。

**Why this priority**: 为后续目录和播放提供共享授权规则。
**Independent Test**: 用服务端测试夹具覆盖下方完整判定表，验证允许结果和拒绝原因，不需要真实媒体源。

**Acceptance Scenarios**:

1. **Given** 媒体同时在允许与禁止名单，**When** 判定，**Then** 禁止。
2. **Given** 家庭可用的已评级超限媒体被明确允许，**When** 判定，**Then** 允许；家庭禁用或跨家庭媒体仍禁止。
3. **Given** 未评级媒体且不允许未评级，**When** 判定（含媒体在允许名单），**Then** 禁止。
4. **Given** 儿童观看频道，**When** 不在频道允许名单，**Then** 禁止；在名单中仍检查未评级或等级规则。
5. **Given** 会话当前档案缺失、停用或策略缺失，**When** 判定，**Then** 拒绝，不回落成人策略。

### User Story 3 - 防止儿童自助解除限制 (Priority: P1)

主账号会话可承载儿童观看，但不能因此授予儿童变更策略和绕过档案保护的能力。

**Why this priority**: V1 只有一个主要账号，owner 角色无法区分当前拿设备的人。
**Independent Test**: 以主账号会话选择儿童档案，直接调用管理或成人切换操作，无密码/PIN 时全部拒绝；正确验证后成功。

**Acceptance Scenarios**:

1. **Given** 儿童观看中的主账号会话，**When** 修改策略、创建档案、编辑档案或清除 PIN，**Then** 必须重新验证主账号密码；伪造管理状态无效。
2. **Given** 家庭存在任一儿童档案，**When** 切换至未设 PIN 的成人档案，**Then** 必须验证主账号密码；已设 PIN 的成人档案继续走原有 PIN 解锁流程。
3. **Given** 家长验证失败，**When** 换浏览器会话或换档案重试，**Then** 不能绕过按账号共享的失败次数限制。
4. **Given** 无当前档案或仅成人家庭，**When** 执行管理写操作，**Then** 仍须家长验证；不以当前档案类型决定管理权限。

### Edge Cases

- 空允许名单不表示“允许所有”；空频道名单对儿童表示所有频道不可访问。
- 同一媒体同时允许/禁止可以存储，禁止优先；名单重复项去重，不跨名单删除。
- 等级上下界、非整数、未知字段、超长名单、损坏策略、并发保存必须有确定结果。
- 未评级与无法识别的外部分级等价；不能用频道名、播放地址或前端上报等级推定安全。
- 停用档案可保留和编辑策略，但不能作为当前观看者。
- 已有会话在策略提交后的下一次授权必须使用新策略；本阶段不承诺终止已建立的播放流。
- 升级有儿童家庭时清空未设 PIN 成人档案的活动会话上下文，要求重新选择并验证，不使旧会话绕过新增规则。

## Requirements

### Functional Requirements

- **FR-001**: 每个档案持久化唯一策略，并严格绑定档案所属家庭。
- **FR-002**: 默认成人最高等级 18、允许未评级；默认儿童最高等级 12、禁止未评级；三类名单均为空。等级为内部年龄阈值 0～18 的整数，不声称是法定或地区分级。
- **FR-003**: 新建档案与默认策略原子创建；升级对既有档案补齐策略；运行时缺失或损坏策略必须拒绝，不能静默补宽松策略。
- **FR-004**: 仅主账号可以管理策略，所有管理写操作须重新验证该账号密码。验证不能使用客户端缓存标记或档案 PIN 替代。
- **FR-005**: 策略按下表判定，第一条命中即结束；账号角色不得覆盖内容策略。
- **FR-006**: 授权档案来自已验证设备会话；任何客户端传入的档案、家庭、等级、资源可用状态不得改变授权上下文。
- **FR-007**: 策略修改在提交后的下一次授权生效，包括已登录的其他设备；不以客户端刷新作为条件。
- **FR-008**: 默认策略只用于创建和迁移，不因刷新、登录或档案重选覆盖已保存策略。本阶段不提供修改档案类型或“一键重置”入口。
- **FR-009**: 保存为整体替换且检查版本，旧版本保存拒绝；失败不能修改已有值。阶段 2 的“整体”指可编辑配置（最高等级、未评级开关）的原子整体替换，三类名单由服务端原样保留（见 contracts/api.md 与 FR-013），不以请求覆盖或清空。
- **FR-010**: 提供主账号策略管理界面，明确未评级与频道允许名单的局限；保存失败保留输入，冲突提示重新加载，不能假成功。
- **FR-011**: 缺失/错误家长验证不修改数据；连续 5 次错误锁定 5 分钟，锁定中正确密码也拒绝。计数按账号共享且重启保留，成功后清零。
- **FR-012**: 家庭存在儿童档案时，未设 PIN 成人档案的选择须家长验证；有 PIN 的成人档案保留原有解锁流程。创建/编辑档案与 PIN 管理同样受 FR-004 保护，不能通过新建成人档案绕过。
- **FR-013**: 名单仅接受去重后至多 1000 个非空有效媒体标识；本阶段无媒体目录，不向用户开放未经资源归属校验的标识编辑，默认空名单；使用服务端夹具证明名单读写和判定。阶段 3 在启用编辑前必须接入同家庭资源选择与归属验证。
- **FR-014**: 跨家庭/账号和不存在的目标对外不可区分；新增策略接口的未知字段与非法策略值拒绝；既有身份接口继续忽略未知身份字段，不能将其作为信任源，密码/PIN/令牌不写日志或响应。
- **FR-015**: 阶段 2 交付策略持久化、管理、规则核心和服务端调用契约。目录过滤、真实媒体详情/下载和播放拦截须在阶段 3/4 接入验收，不能凭本阶段测试宣称已拦截真实媒体。

### 策略判定表

| 顺序 | 条件 | 结果 |
| --- | --- | --- |
| 1 | 无有效会话或无可用当前档案 | 拒绝 |
| 2 | 资源不属于当前家庭、不存在或家庭禁用 | 拒绝 |
| 3 | 策略缺失或损坏 | 拒绝 |
| 4 | 媒体在禁止名单 | 拒绝 |
| 5 | 儿童观看频道且频道不在允许名单 | 拒绝 |
| 6 | 媒体未评级 | 仅按 allowUnrated；媒体允许名单不覆盖此项 |
| 7 | 已评级媒体在允许名单 | 允许，可覆盖普通等级上限 |
| 8 | 已评级媒体等级不超过最高等级 | 允许 |
| 9 | 其他情况 | 拒绝 |

儿童频道允许名单是必要条件，不是节目级安全承诺。成人不受频道允许名单限制，但仍受禁止名单、未评级及等级规则约束。

### Key Entities

- **ProfilePolicy**：家庭与档案归属、最高内容等级、未评级开关、三类名单、保存版本。
- **受信任媒体事实**：由服务端资源目录提供的媒体身份、归属、类型、分级及家庭可用状态；本阶段仅用夹具。
- **家长验证状态**：主账号的失败计数和锁定时间；不保存明文密码，不产生永久管理模式。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 新建与升级的档案均有且仅有一份策略；重启后已保存配置 100% 保留。
- **SC-002**: 判定表各分支、名单冲突、未评级与儿童频道组合场景全部符合预期。
- **SC-003**: 篡改档案、家庭、角色、客户端状态、等级或资源状态的负向场景全部无法扩大权限。
- **SC-004**: 儿童使用主账号会话时，所有扩大观看范围的管理和切换路径在无有效验证时均失败。
- **SC-005**: 两设备会话下修改策略，另一设备下一次授权即采用新值；并发旧版本保存被拒绝且数据不变。
- **SC-006**: 临时数据升级、回滚到阶段 1、再次升级与备份恢复均通过，阶段 1 身份与 PIN 数据不丢失。
- **SC-007**: 真实浏览器与真实服务完成策略读取/保存、验证失败与锁定、冲突提示；单元结果不得替代此证据。

## Assumptions

- 维护者于 2026-10-23 确认：内部年龄阈值 0～18，儿童默认 12、成人默认 18；修改策略、创建档案或改 PIN 前重新验证主账号密码。
- 2026-10-23 维护者接受本规格与 ADR-0006 全部开放项：成人默认允许未评级、儿童默认禁止未评级；连续 5 次失败锁 5 分钟；未设 PIN 成人切换保护与名单覆盖顺序按本文与 ADR-0006 生效。
- “明确允许覆盖等级”不覆盖未评级开关，也不覆盖儿童频道允许名单；该保守细化已随 ADR-0006 接受并同步领域文档。
- MediaItem/频道实体在阶段 3 定义；本阶段不引入虚构媒体表、播放器或 IPTV/EPG 导入。
- 默认儿童首次接入未评级频道时即使加入允许名单仍被拒绝；需要家长显式开启未评级，界面必须说明。
- 阶段 3 接入前，名单编辑控件显示“媒体目录接入后可配置”，不得输入任意 ID 冒充已验证资源。
