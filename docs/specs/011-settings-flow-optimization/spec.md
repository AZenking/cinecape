**Created**: 2026-11-01

**Status**: Proposed

**Governance**: 遵循 `.specify/memory/constitution.md`；按 Proposed → Accepted → Implementing → Verified 流转。本文由维护者指定将优化提案整理为规格，不授权实施，不改变现行授权规则，不代表功能已实现。设计来源采用交互原则（Apple HIG Settings/Managing accounts/Alerts 的「减少不必要身份门槛、少用打断式确认、恢复最近位置」），不照搬原生窗口能力，也不承诺生物识别。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 管理解锁一次，普通管理操作零重复验证 (Priority: P1)

已登录的主档案管理员进入设置中的家庭管理区域时，至多进行**一次**账号密码解锁（本会话刚验证过账号时甚至零次、只需点击解锁）；此后在七个业务模块之间切换、短时返回观看页再回来、刷新页面，都不再被索要任何凭据。有效期由服务端控制（空闲 15 分钟、自首次解锁起最长 60 分钟），到期、身份变化或手动锁定后需要重新解锁。独立的「设置 PIN」验证步骤被取消；档案 PIN 仅保留用于共享设备选档与儿童隔离。

**Why this priority**: 重复验证是当前打断最频繁、影响所有管理任务的问题（提案 S07/S08 与第 4 章核心）；它也是其余故事的基础交互。

**Independent Test**: 以已登录主档案管理员连续浏览并保存七个模块、中途返回观看页并刷新，统计全程凭据输入次数；再用可控时间验证空闲与最长期限、以及身份变化后的强制失效。仅本故事即可交付「管理不再被打断」的完整价值。

**Acceptance Scenarios**:

1. **Given** 已登录主档案且无有效管理授权，**When** 进入任一家庭管理模块，**Then** 显示一个「解锁家庭管理」面板，输入一次当前账号密码后直达原目标页；全程不出现独立的「设置 PIN」步骤。
2. **Given** 管理授权有效，**When** 在七个模块间切换、短时返回观看页再回到设置、或刷新/重新打开页面，**Then** 凭据输入次数为 0，且页面解锁、身份菜单入口与直达链接表现为同一个授权事实。
3. **Given** 本会话最近 5 分钟内刚完成账号密码登录或等价账号验证，**When** 用户点击「解锁家庭管理」，**Then** 不重复索要同一密码，核验通过后直接签发授权。
4. **Given** 空闲超过 15 分钟或距首次解锁超过 60 分钟，**When** 再执行管理操作，**Then** 必须重新解锁；期间的后台轮询、自动刷新、页面保活与鼠标移动均未延长有效期。
5. **Given** 用户点击「锁定家庭管理」，或发生退出、切换档案、会话/设备撤销、账号密码/PIN/主档案变化、档案停用、服务重启或恢复备份，**When** 后续尝试管理操作，**Then** 授权已失效、受保护内容不再展示，需重新解锁。
6. **Given** 当前账号不具备管理角色，**When** 进入家庭管理，**Then** 得到「没有管理权限」的解释，不反复弹出凭据输入。
7. **Given** 当前登录账号正确但活动档案不是主档案，**When** 进入家庭管理，**Then** 明确提供「切换到主档案」入口（沿用既有选档保护），切换后继续原管理意图；不静默切换身份，也不额外要求设置 PIN。

### User Story 2 - 编辑保护：取消、导航、到期都不丢非敏感草稿 (Priority: P2)

管理员在任意设置表单中的未保存修改都受到保护：导航离开前先被拦截（保存并离开/不保存/继续编辑）；管理授权到期时冻结写入并暂存非敏感编辑，重新解锁后按服务器现值核对恢复；保存范围明确，成功后只清理已提交的字段；密码、PIN、来源密钥等敏感字段绝不进入草稿。

**Why this priority**: 直接保护用户劳动成果（提案 S01/S02/S03 与第 5.2/5.3 节）；与 Story 1 的授权机制协作但可独立验收（导航保护、保存范围、草稿清理均不依赖新授权生效）。

**Independent Test**: 在各表单制造未保存修改，分别执行导航离开、取消解锁、授权到期、保存失败、版本冲突五类操作，逐项核对草稿保留范围与敏感字段清除；不触发新授权签发也可验证拦截与保留行为。

**Acceptance Scenarios**:

1. **Given** 表单存在未保存修改，**When** 导航离开、关闭编辑面板或同页切换目标档案，**Then** 先出现「保存并离开 / 不保存 / 继续编辑」；打开未改动的空表单不算脏状态，不触发拦截。
2. **Given** 「保存并离开」需要验证，**When** 用户取消验证，**Then** 留在原表单、输入完整保留，且没有发生任何写入。
3. **Given** 管理授权到期，**When** 用户正处于编辑状态，**Then** 新管理请求与轮询暂停、受保护详情隐藏，非敏感编辑被暂存并提示「家庭管理已锁定，未保存的编辑已暂存」，提供「解锁继续」与「放弃编辑」。
4. **Given** 到期后重新解锁且服务器现值版本未变，**When** 选择恢复，**Then** 非敏感编辑恢复；版本已变化时展示「服务器现值 / 我的修改」供用户合并或放弃；任何情况下不自动重放保存请求。
5. **Given** 编辑过程结束（到期、放弃、身份失效、刷新或关闭页面），**When** 检查草稿与本地存储，**Then** 密码、PIN、来源地址中的密钥等敏感字段 0 保留；草稿仅存在于当前页面会话，身份失效即被清除，另一身份无法恢复。
6. **Given** 内容权限编辑完成，**When** 保存，**Then** 一次提交同一目标的完整差异，成功后仅清理已提交字段，不影响其他未提交草稿。

### User Story 3 - 高影响动作当次验证，直达动作不双输密码 (Priority: P3)

普通管理操作在授权期内零额外凭据；真正的高影响动作（修改/清除/找回档案 PIN、修改账号密码、转移主档案、撤销设备会话、异常导入发布等）仍需当次账号密码验证，但验证与动作表单合而为一：直达深链接时不出现「先解锁输一次、确认动作再输一次」；验证结果仅用于本次明确提交的动作，取消则无任何写入。

**Why this priority**: 安全边界——本故事保证减少验证次数不以削弱高影响动作保护为代价（提案 4.2 矩阵与「合并验证」要求）；优先级低于前两者是因为其交互依附于解锁面板与表单结构。

**Independent Test**: 逐项执行验证矩阵中的高影响动作，统计额外凭据输入次数并验证单次合并输入；直达高影响深链接验证「一次密码完成授权+动作」；取消验证后确认零写入。可在 Story 1 交付前后分别独立测试。

**Acceptance Scenarios**:

1. **Given** 管理授权有效，**When** 查询频道、筛选候选、测试来源、查看任务状态等普通管理操作，**Then** 额外凭据输入为 0，反馈为行内加载与结果。
2. **Given** 修改/清除/找回档案 PIN、修改账号密码、转移主档案、撤销设备会话，**When** 提交，**Then** 当次账号密码验证在动作自身的单个表单/弹层内完成（同时说明对象与后果），不先弹解锁再弹第二次密码框。
3. **Given** 用户直达一个高影响动作深链接且无有效授权，**When** 验证面板出现，**Then** 管理授权与当次动作验证合并为一次密码输入；密码通过后仅执行该明确提交的动作，不顺带执行其他等待中的动作。
4. **Given** 任一当次验证完成或被取消，**When** 后续操作发生，**Then** 该验证不可转用于其他操作；取消路径无任何写入。
5. **Given** 导入结果包含显著删除或其他异常变更，**When** 发布，**Then** 一次确认展示真实差异（新增/更新/缺失及影响）并解释原因；取消发布保留上次成功目录。

### User Story 4 - 七模块任务流：错误可见、来源可选、结果可达 (Priority: P4)

七个业务模块（账号与安全、档案管理、内容权限、媒体来源、节目单、设备管理、通用设置）获得完整任务流：EPG 匹配优先关联来源并允许明确切换；来源与设备记录完整分页；读取失败与空结果明确区分并可重试；选择器可搜索、不用手抄内部 ID；时间统一转换并标注时区；导入转后台任务并在成功后提供准确的结果入口。

**Why this priority**: 修复提案 S04–S06、S09–S12 的任务流质量问题，覆盖面最广；但其体验建立在前面故事确立的验证、保存与反馈框架之上，故列最后。

**Independent Test**: 在 ≥20 个来源、≥50 条设备记录与多 EPG 来源环境下走完七个模块主流程，逐项核对错误/空态区分、分页完整遍历、EPG 来源选择、时间标注与导入结果入口；不依赖新授权机制也可用现行授权完成验证。

**Acceptance Scenarios**:

1. **Given** 存在多个 EPG 来源且其中有与该 IPTV 关联的来源，**When** 进入频道匹配，**Then** 默认优先关联来源、允许明确切换；查询、筛选与保存匹配全程无验证弹窗；查询失败显示错误与重试，不以空结果冒充。
2. **Given** ≥20 个媒体来源或 ≥50 条设备记录，**When** 浏览对应列表，**Then** 完整翻页、显示总数量与空态；设备播放记录按设备查询，不进入公共/个人缓存。
3. **Given** NAS 目录读取失败，**When** 打开目录选择，**Then** 界面区分「加载中 / 未配置 / 读取失败」并提供重试，不以空列表冒充无内容。
4. **Given** 来源导入成功，**When** 用户点击结果入口，**Then** 按类型跳转到正确位置（IPTV→直播、EPG→节目单、NAS→媒体库、VOD→对应来源的在线内容入口）；目标页不支持定位到该来源时，先说明跳转范围，不声称已定位。
5. **Given** 长耗时导入已提交，**When** 用户离开页面后返回，**Then** 任务继续运行且状态被恢复；网络断开时仍可查询任务状态，重新尝试复用同一提交标识，不产生重复任务；授权到期不影响任务运行（提示「导入继续运行，解锁后查看结果」）。
6. **Given** 家庭节目时间与设备活动时间同时可见，**When** 展示，**Then** 分别按家庭时区与明确标注的显示时区转换并标注，相对时间仅作辅助、不掩盖准确时间；家庭时区不因浏览器时区变化被自动覆盖。
7. **Given** 需要选择档案、语言、时区或来源，**When** 交互，**Then** 提供可搜索选择器与自然语言说明；内部 ID 与错误码仅出现在按需展开的诊断详情中。

### Edge Cases

- **网络错误 vs 密码错误**：解锁或当次验证遇到网络故障时显示「暂时无法核验，请重试」，不伪装成密码错误或账号锁定。
- **版本冲突**：重新解锁后发现服务器现值已变化 → 展示「服务器现值 / 我的修改」对比，由用户合并或放弃；后提交者收到冲突且草稿保留。
- **刷新/关闭页面**：有未保存修改时给出原生未保存提示；本期不承诺刷新后恢复草稿（草稿仅限当前页面会话）。
- **游客直达管理深链接**：先进入登录流程，不提前读取或展示任何管理数据；家庭区域在未解锁时只显示锁定说明。
- **授权有效但任务进行中**：到期不等于导入失败，界面说明「导入继续运行，解锁后查看结果」；断网时允许查询状态、不盲目创建重复任务。
- **共享设备**：管理授权有效期间能操作已解锁主档案的人可进行普通管理修改——以主档案限制、空闲锁定、最长有效期和手动锁定控制该窗口；不默认永久信任设备。
- **语言与时区的真实能力边界**：未支持完整界面翻译时，语言字段不得描述为立即切换整个界面；家庭时区影响节目单，不被浏览器时区自动覆盖。
- **编辑中途的外部变化**：EPG 来源改名、停用或候选歧义发生在编辑过程中时，保存前按服务器现值核对并提示。
- **到期前提示**：到期前两分钟可显示非模态提示；连续操作按服务端规则续期，不展示每秒倒计时。

## Requirements *(mandatory)*

### Functional Requirements

**管理授权（Story 1）**

- **FR-001**: 系统 MUST 以一次账号密码「解锁家庭管理」作为唯一的管理验证入口，取消独立的「设置 PIN」验证步骤；档案 PIN 仅保留用于共享设备选档与儿童隔离，不承担账号级管理权限。
- **FR-002**: 管理授权 MUST 由服务端签发、核验、续期与撤销；有效期规则：空闲 15 分钟、自首次解锁起最长 60 分钟；仅经服务端确认的前台用户管理操作可刷新空闲期限。
- **FR-003**: 后台任务轮询、自动刷新、页面保活与鼠标移动 MUST NOT 续期管理授权；客户端仅展示状态，期限判定以服务端为准。
- **FR-004**: 退出、切换档案、会话或设备撤销、账号密码/PIN/主档案变化、档案停用、服务重启或恢复备份 MUST 立即使管理授权失效。
- **FR-005**: 设置页 MUST 提供「锁定家庭管理」手动锁定入口，锁定不影响观看登录状态。
- **FR-006**: 本会话最近 5 分钟内已完成账号密码登录或等价账号验证时，系统 MUST 允许用户仅明确点击「解锁」即获得管理授权（零凭据输入，但不得静默签发）。
- **FR-007**: 无有效授权进入家庭管理区域时，系统 MUST 显示锁定说明与一个解锁面板，不提前读取或展示管理数据；已登录用户始终可打开设置外壳及有权访问的个人区域；游客尝试账号或家庭操作时才进入登录流程。
- **FR-008**: 活动档案非主档案时 MUST 提供明确的「切换到主档案」入口（沿用既有选档保护），切换后继续原管理意图；账号角色不足时 MUST 给出解释而非反复凭据提示。
- **FR-009**: 打开设置 MUST 恢复当前账号最近查看的有权访问分类（深链接优先于该记忆），退出时清理账号级位置记忆且不跨账号复用，无历史时进入账号与安全；设置页 MUST 始终提供返回观看入口、当前身份与家庭管理锁定状态。
- **FR-010**: 设置 MUST 保留现有七个业务模块及其深链接；侧栏按用途分组（个人 / 家庭管理 / 账号），个人偏好与家庭配置 MUST 分别标明作用范围。

**验证分级与当次验证（Story 3）**

- **FR-011**: 查看家庭配置、查询筛选、测试来源、查看任务状态等普通管理操作 MUST 仅要求有效管理授权，无额外凭据输入、无确认弹窗。
- **FR-012**: 高影响动作（修改/清除/找回档案 PIN、修改账号密码、转移主档案、撤销设备会话、异常导入发布等）MUST 完成当次账号密码验证；验证仅绑定本次对象、版本与动作，不得转用于其他操作。
- **FR-013**: 直达高影响动作深链接且无授权时，系统 MUST 将管理授权与当次动作验证合并为一次密码输入；密码通过后仅执行用户明确提交的动作。
- **FR-014**: 每次管理请求 MUST 由服务端重新校验角色、归属、身份版本与授权有效期；既有版本冲突、限流与失败锁定机制 MUST 保留。
- **FR-015**: 修改账号密码 MUST 在动作表单内完成当前密码验证（一次），成功后明确说明需重新登录并清除旧身份与授权；不新增前置解锁步骤。

**编辑保护与草稿（Story 2）**

- **FR-016**: 文本表单、来源配置与内容权限 MUST 采用显式保存；字段未变化时保存禁用；设备本地、可撤销的简单偏好可即时生效，但不扩大到家庭配置与权限修改。
- **FR-017**: 存在未保存修改时的导航、关闭编辑面板与同页切换目标档案 MUST 先行拦截，提供「保存并离开 / 不保存 / 继续编辑」；空表单不算脏状态。
- **FR-018**: 保存需要验证时，验证 MUST 仅在用户选择「保存并离开」后发起；验证取消、保存失败或版本冲突时 MUST 留在原表单并保留输入。
- **FR-019**: 管理授权到期 MUST 冻结新的管理写入与轮询、隐藏受保护详情、暂存当前会话的非敏感编辑快照，并提供「解锁继续」与「放弃编辑」；重新验证后按服务器现值版本核对恢复，任何情况下 MUST NOT 自动重放保存请求。
- **FR-020**: 密码、PIN、来源地址中的密钥等敏感字段 MUST NOT 进入草稿、长期浏览器存储或任何持久缓存；非敏感草稿仅保留在当前页面会话内，身份失效时 MUST 清除且不得被另一身份恢复。
- **FR-021**: 内容权限 MUST 以统一「保存内容权限」动作一次提交同一目标的完整编辑差异，成功后仅清理已提交字段；以目标名称、差异摘要与提交前权限检查防止误操作，不以重复输密码补偿界面不清楚。
- **FR-022**: 任务提交时 MUST 冻结本次提交快照并在提交中防止重复请求；同一提交的重试 MUST 复用同一幂等标识。

**模块任务流与反馈（Story 4）**

- **FR-023**: EPG 匹配 MUST 优先使用与该 IPTV 关联的来源并允许明确切换；查询、筛选、测试与匹配全程无验证弹窗。
- **FR-024**: 媒体来源列表与设备记录 MUST 支持完整分页并显示数量与空态；≥20 个来源、≥50 条设备记录可完整遍历；设备播放记录按设备查询，不进入公共/个人缓存。
- **FR-025**: NAS 目录读取 MUST 区分加载中、未配置与失败三种状态并支持重试；所有来源/EPG 操作失败 MUST 与空结果明确区分并给出重试入口。
- **FR-026**: 界面 MUST NOT 要求手动抄写内部 ID；选择类输入提供可搜索选择器，技术术语以自然语言说明，内部 ID 与错误码仅出现在按需展开的诊断详情。
- **FR-027**: 家庭节目时间 MUST 按家庭时区显示并标注；设备活动时间 MUST 按明确标注的显示时区转换；相对时间仅辅助，不得掩盖准确时间。
- **FR-028**: 长耗时导入 MUST 转为后台任务，离开页面不取消服务器任务，返回时恢复任务状态；授权到期不影响任务运行，网络断开时仍可查询任务状态。
- **FR-029**: 来源导入成功后 MUST 按类型提供准确的结果入口（IPTV→直播、EPG→节目单、NAS→媒体库、VOD→对应来源的在线内容入口）；目标浏览页不支持来源定位时 MUST 先说明跳转范围。
- **FR-030**: 异常快照发布 MUST 仅展示真实差异（新增、更新、缺失及影响）并在需确认时解释原因；取消发布保留上次成功目录。
- **FR-031**: 失败反馈 MUST 区分字段校验、密码错误、网络故障、无权限、授权到期与版本冲突，分别给出有效动作；网络错误 MUST NOT 伪装为凭据错误或锁定。
- **FR-032**: 确认弹层仅用于不可逆、高影响或需立即决策的操作；普通成功采用行内状态或轻提示；验证弹层至多一层、不叠加。

**可访问性与呈现（Story 4 / 全局）**

- **FR-033**: 验证与确认弹层 MUST 管理焦点（进入弹层、关闭后返回）、支持键盘操作与取消；验证失败聚焦错误或输入且不清空其他编辑。
- **FR-034**: 布局 MUST 在宽窗口保留侧栏、窄窗口收拢；标题始终显示当前分类；200% 缩放与低高度窗口下保存与取消按钮不被遮挡。
- **FR-035**: 语言与时区选择 MUST 使用可搜索选择器；语言字段 MUST NOT 描述为立即切换整个界面（除非实际支持）；家庭时区 MUST NOT 因浏览器时区变化被自动覆盖。

**规格与契约同步（治理）**

- **FR-036**: 本方案被接受后，现行独立「设置 PIN」、固定 15 分钟不续期与敏感操作逐次密码规则（ADR-0011、规格 005 FR-028/FR-030/FR-031/FR-033/FR-040/FR-041 及对应 API/UI 契约）MUST 按替代关系更新；MUST NOT 仅在前端隐藏弹层而保留后端规则不变。

### Key Entities *(include if feature involves data)*

- **管理授权**：服务端保存的家庭管理访问事实。绑定账号、设备会话、主档案与身份/PIN/主档案版本；携带空闲期限与最长期限；由 FR-004 所列事件撤销；不保存原始密码或 PIN，不永久信任设备。
- **当次动作验证**：一次性凭据核验结果，绑定本次对象、版本与动作，不可转用于其他操作；可与管理解锁合并发起（FR-013）。
- **非敏感草稿快照**：当前页面会话内的编辑暂存；明确排除密码、PIN、来源密钥等敏感字段；身份失效即清除；恢复前与服务器现值做版本核对。
- **设置位置记忆**：账号级「最近查看分类」记录；深链接优先；退出清理；不跨账号复用。
- **管理任务**：来源导入/同步等长耗时后台任务；携带幂等提交标识与用户可读状态（正在获取 / 等待确认 / 已发布 / 失败可重试）；与管理授权解耦（到期不取消任务）。
- **沿用既有实体**：账号、档案（主档案/成人/儿童）、媒体来源、EPG 来源与匹配、设备会话、内容策略——本方案不改变其身份隔离边界，仅改变验证触发方式与反馈质量。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 凭据输入次数达到提案第 8 章目标——7 个场景（新建来源后导入、匹配一个频道、再搜索筛选候选、同一授权内连续修改多模块、有效授权内离开再返回、转移主档案/撤销设备、修改账号密码）实测值全部 ≤ 目标值；已解锁状态下普通管理操作新增凭据输入为 0 次。
- **SC-002**: 单一授权事实——页面解锁、身份菜单入口与直达链接共享同一服务端授权；有效授权内七模块切换 + 返回 + 刷新的重复索要凭据次数为 0；解锁失败不得显示为成功（负向用例 100% 通过）。
- **SC-003**: 期限可控——空闲 15 分钟与最长 60 分钟以服务端可控时间验证通过；轮询/自动刷新/鼠标移动产生的续期次数为 0；手动锁定即时生效。
- **SC-004**: 草稿保护——导航拦截、验证取消、保存失败、版本冲突、授权到期五类场景下，非敏感编辑按恢复规则保留率 100%，敏感字段保留 0 处，自动重放保存请求 0 次。
- **SC-005**: 错误可见——来源/EPG/NAS 全部失败路径呈现「错误 + 重试」，以空态冒充失败的用例为 0；多 EPG 来源场景 100% 按明确选择匹配。
- **SC-006**: 完整遍历——20 个来源与 50 条设备记录的分页遍历可达率 100%，总数与空态展示正确。
- **SC-007**: 越权负向——普通/儿童档案、失效会话、已撤销设备、跨家庭请求对管理数据的读取与修改 100% 被拒绝；敏感字段与权限读取不出现在公共缓存。
- **SC-008**: 任务连续性——导入后台化后离开页面返回，状态恢复成功率 100%，重复任务产生 0 个；断网查询与幂等重试行为符合 FR-022/FR-028。
- **SC-009**: 可用性——键盘操作、200% 缩放、窄窗与低高度窗口下完成解锁、编辑、保存、取消全流程的可达率 100%；家庭与设备时间 100% 带时区标注。

## Assumptions

- **参数为工程建议值**：空闲 15 分钟、最长 60 分钟、登录新鲜度 5 分钟来自提案建议而非外部强制；接受后可在替代 ADR/契约中调整数值，调整不改变本规格的结构与验收方式（SC-003 按当时契约值验证）。
- **存量「设置 PIN」数据处置**：本规格假定存量设置 PIN 数据默认保留但停止用于管理验证；其清除或迁移方式在替代 ADR 中决定，不阻塞本期交付。
- **个人偏好区域**：本期不新增具体个人偏好项；仅建立个人/家庭作用范围分组与标注能力，无可用项时不显示空区域。
- **Passkey 与生物识别不在本期范围**：作为后续增强需单独设计注册、设备兼容与恢复；当前不得把按钮标成系统生物识别能力。
- **界面完整翻译不在本期范围**：语言字段仅保存偏好并说明实际生效范围。
- **游客与公共浏览边界沿用现行规则**（005/010），本方案仅改变「尝试账号或家庭操作时」的进入方式。
- **依赖既有机制**：登录会话、账号角色、主档案判定、设备会话撤销、版本冲突、限流与失败锁定均沿用现有实现；本方案不引入新的身份模型。
- **证据要求**：验收包含服务端授权测试与真实浏览器流程测试；静态测试通过不能替代运行时与真实来源联调证据（宪章原则一）。
