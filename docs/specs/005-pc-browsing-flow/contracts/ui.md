# UI Contract: PC 首页、直播、节目墙与设置

状态：Proposed；依据 spec.md 五项澄清、research.md R9。不是视觉原型或浏览器验收结果。所有通用交互用 HeroUI v3，业务授权由服务器执行。

## 1. 路由、布局与返回语境

| URL | 布局 / 页面 | 访问与状态 |
| --- | --- | --- |
| `/` | PublicLayout / HomePage | 游客公共区；登录选档后个人区 |
| `/vod` | PublicLayout / VodCatalogPage | 沿用基础搜索、类型、分页；不做独立点播产品设计 |
| `/media/:id` | PublicLayout / MediaDetailPage | 元数据公开；进度单独从me读取，继续/从头均受控播放 |
| `/live` | PublicLayout / LivePage | section/group/q/page为公共浏览状态 |
| `/live/guide` | PublicLayout / GuidePage | date/from/channelPage及视图模式，公共可直接打开 |
| `/settings/account` | SettingsLayout | 默认设置模块；须有效会话+主Profile+独立设置PIN |
| `/settings/profiles` | SettingsLayout | 档案、PIN与主档案转移 |
| `/settings/policy` | SettingsLayout | 目标档案、等级、未评级、名单 |
| `/settings/sources` | SettingsLayout | IPTV/NAS来源及导入任务 |
| `/settings/epg` | SettingsLayout | EPG来源、关联、同步和手动匹配 |
| `/settings/devices` | SettingsLayout | 设备、撤销与设备播放记录 |
| `/settings/general` | SettingsLayout | 家庭名、语言、时区 |

公共Layout不被RequireSession包裹；SettingsLayout使用路由守卫但最终权限仍在API。旧根路径档案页和独立来源/设备/档案管理路由移除，不设置长期旧路由兼容。未知路由显示可返回首页的404页面，不跳到档案选择。公共页直接刷新仍可加载。

目录q/type/page和节目墙date/from/channelPage写入查询参数，滚动锚点保存在当前导航状态；私人缓存不写URL。详情返回或弹层取消恢复原位置。只接受本应用白名单内部返回目标；未解锁设置直达保存目标但不预取管理内容。

## 2. 公共壳与身份状态

顶部品牌返回首页；左侧首页/点播/直播为真正路由链接。右侧：游客=登录；session restoring=轻量恢复状态（不遮挡公共区）；登录未选档=账号+选择Profile；已选档=账号+头像/名称及菜单。普通档案菜单提供切档/退出；只有当前主Profile提供设置入口，但隐藏入口不能替代API校验。

公共数据请求credentials omit，服务端公共投影与身份无关；个人请求Session认证，响应缓存key包含Household/Profile/contextVersion。换档/退出先清旧个人展示并增加前端generation，迟到结果不能回填。个人区错误不覆盖公共页面。

## 3. 统一弹层与意图状态机

```text
idle
├── uninitialized → initialize → login
├── loginRequested / anonymousPlay → login
└── authenticatedAction
    ├── noProfile + bootstrapRequired → bootstrap → picker
    ├── noProfile → picker → selectionPin（需要时）
    └── profileReady
        ├── play → authorize → prepare → playing
        ├── favorite → saveFavorite
        └── settings → settingsPin → settingsPage
```

只挂载一个受控Modal，内容切换步骤；不可同时叠出登录、选档和PIN三个模态框。每次动作保存intentId、目标、调用入口、取消状态；新动作递增代次，旧回调不可起播或打开设置。取消返回原页面、清输入凭据、取消当前意图，不自动重开。

initialize只配置账号基础，201后显式登录；bootstrap由用户填写姓名+6位PIN+当次账号密码，成功后进入picker，不静默激活主档案。选择受PIN保护档案先走选档unlock再select；设置需要另一次独立PIN验证。恢复PIN是受限账号密码流程，成功后不直接打开设置。

实现依据官方Modal文档：Backdrop控制isOpen/onOpenChange，Container设置尺寸及scroll=inside，Dialog有标题和描述；实施前核验锁定3.2.6导出。Form提交onSubmit，Button动作onPress；密码只保留表单内存，关闭清空，禁止写localStorage。验证错误映射FieldError或表单Alert，忙时阻止重复提交并保留取消/恢复策略。

播放开始后的首次started进度确认前，seek与会重建输出的音轨切换禁用或排队；确认后恢复，避免generation改变阻断首次样本重试。取消、重试新播放意图和空stop仍可用，不允许因等待历史保存困住播放器。

## 4. 首页

登录选档后顺序：收藏频道→点播观看历史→公共此刻直播摘要及内容入口；游客仅公共区和轻量登录提示，不用空白个人区域占首屏。公共摘要按直播稳定排序取前4项；查看更多进入直播，所有节目单进入guide当前时段，点播入口进入基础目录。

收藏卡显示频道名/标识、当前节目及时间，暂无节目有文字占位；主动作观看直播，标题进入频道详情，独立星标收藏/取消不冒泡播放。个人区首次取最近20项，网格首行数量随宽度变化，查看更多在本区分页展开，不新增身份不明的个人公共路由。无收藏提示去直播页；失败只重试本区。

历史卡显示媒体标题、海报占位、最近观看时间及位置；点击进入详情，不自动播放。详情有有效进度时展示继续观看和从头播放，二者保留各自startMode并进入统一播放入口；无有效进度、资源变化或已到结尾只从头。不可用项标注不可用，不提供可运行播放按钮。其他Profile进度不出现在公开详情HTML或公共响应中。

## 5. 直播首页

顺序固定：所有节目单入口→正在直播→即将播放→各来源主分组的正在直播。每区20项可继续查看，排序依spec；不限制即将播放为未确认的2小时窗口。当前和下一节目更新周期30秒，页面回到前台立即刷新。

无EPG但可用频道在全部频道/其他区可发现，仍可播放；不能将无节目等同无频道。点击节目卡标题打开频道/节目信息，明确播放按钮播放当前频道；未来/已结束节目注明非回看或预约。收藏按钮和播放分开，游客收藏先登录选档但不播放。

## 6. EPG 墙

默认今天、一次展示该日完整24小时（真实日界 00:00–24:00，终点标签按 EPG 惯例显示 24:00；DST 23/25小时按真实日长）；7日期Tab，带家庭时区；回到现在恢复今天全天窗口。上下游数据不足显示空档或暂无节目，不假设有完整7天导入数据。日期过期409时提示并回今天，丢弃旧窗口响应。

频道页默认20、可改最多50；固定频道列与时间头，节目位置用同一UTC坐标轴计算并按家庭时区格式化。横向滚动只在墙内；全天窗口内横向滚动浏览当日全部时段，23/25小时按真实日长计算；重叠节目视觉布局不能把频道点击对象重叠遮住，当前判定沿用R8。超2000块或2MiB时减少每页频道数，保留原频道页并明确提示，不静默漏节目。

节目按钮有可读标签（频道、标题、起止），未来节目打开详情并提供观看该频道当前直播的明确按钮。提供按频道列表替代视图，复用同一响应，每频道节目按时间排序。使用原生button/链接与语义列表，不声明尚未实现的ARIA grid；键盘可Tab到可见节目，翻页后焦点定位到新窗口标题或对应频道，操作不会掉到页面起点或被隐藏元素困住。

右侧节目详情面板宽窗口可侧栏，窄窗口使用Modal；不并行打开与登录冲突的两个模态框，播放请求替换当前Modal步骤并保留返回信息。

## 7. 设置与授权过期

宽窗口左菜单约220px、右主体min-width:0；窄窗口折叠为菜单按钮或Select，面包屑/标题仍显示当前模块。七模块均有实际业务读取与代表性操作，不建立无法使用的按钮占位。

首次进入settings先GET access，未解锁只显示PIN输入，不提前请求来源/设备/策略；15分钟内返回/刷新仍向服务端核验expiresAt。客户端定时器只控制提示，不能当成权限事实。过期或服务端403时立即隐藏管理主体、终止轮询，不自动提交草稿；显示编辑未保存，PIN重新验证后重读最新版本，再允许用户显式继续编辑。

每次原敏感修改仍弹当次账号密码确认；成功不设置可复用家长态。主档案转移或密码修改使当前授权失效，明确说明需要切档/重登录，不在成功回调继续读设置。返回观看保留登录状态，独立的退出按钮才退出账号。

来源创建结果有开始导入动作；刷新/快照确认发布后有查看内容动作；导入失败提示重试并保留旧目录。EPG管理继续手动来源同步和逐频道匹配，不把新节目墙当成批量匹配工作台。

## 8. 响应式、焦点与视觉状态

- 主要宽度1024/1280/1440/1920/2560、高度768/1080；768窄窗、600高、200%缩放作为降级检查。整页无横向溢出；卡片列数自动适应；导航换行/收拢后仍能访问三入口和身份菜单。
- Modal最大尺寸受viewport约束、内部滚动；首焦点进入可操作内容，关闭回原触发器。若触发器已因身份变化消失，回当前页面标题或新的身份入口。
- 统一加载骨架/Spinner、空状态、可重试Alert、禁用理由、成功反馈；错误不可仅用颜色。长名称截断同时提供完整可读名称，时间数字用等宽数字。
- 延续暗色语义token与统一焦点色，尊重prefers-reduced-motion；不照抄讨论稿中的原始hex值为第二套主题。
- ScrollShadow可提示溢出，但不作为虚拟化或无障碍网格已完成的证明。
