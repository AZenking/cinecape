# 设置流程优化方案（Apple HIG 参考）

日期：2026-11-01。状态：待评审提案。本文不改变现行授权规则，不代表功能已经实现。

## 1. 目标与设计依据

目标：普通用户进入设置不被验证打断；管理员完成一次来源配置或节目单匹配时，只做一次必要的身份验证；高影响动作仍有清楚的确认和保护；取消、失败、到期都不丢非敏感编辑。

参考 Apple Human Interface Guidelines：

- [Settings](https://developer.apple.com/design/human-interface-guidelines/settings)：合理默认值、减少设置数量、把任务选项留在任务上下文、恢复最近查看的设置分类。
- [Managing accounts](https://developer.apple.com/design/human-interface-guidelines/managing-accounts)：避免不必要的身份门槛、减少凭据输入、在可支持时采用 passkey。
- [Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts)：少用打断式弹窗；普通、可撤销操作不反复确认；提示具体结果与可执行动作。

下文的验证分级、15 分钟空闲期限及 60 分钟最长有效期均为本工程建议，不是 Apple 指定参数。redRoad 当前是 Web 工程，采用交互原则，不直接照搬原生窗口或承诺 Face ID 能力。

## 3. 推荐的设置结构

保留现有七个业务模块及深链接，侧栏按用途分组，避免增加独立的顶层页面。

| 分组 | 模块 | 展示内容与边界 |
| --- | --- | --- |
| 个人 | 通用设置中的个人偏好区域 | 仅设备本地、非敏感且确有支持的偏好；无可用项时不新增空区域 |
| 家庭管理 | 档案管理、内容权限、媒体来源、节目单、设备管理 | 涉及家庭共享数据，需要一次管理解锁 |
| 账号 | 账号与安全 | 本人账号基本信息可读，凭据变更按高影响动作处理 |
| 家庭管理 | 通用设置中的家庭区域 | 家庭名称、共享语言与家庭时区，需要管理解锁 |

个人偏好与家庭配置必须分别标明作用范围。家庭时区影响节目单，不应因浏览器时区变化被自动覆盖。未支持完整界面翻译时，语言字段不能被描述为会立即切换整个界面。

设置入口保留在身份菜单。已登录账号可打开设置外壳及有权访问的个人区域；家庭区域显示锁定说明，不提前读取或展示管理数据。游客继续公共浏览，尝试账号或家庭操作时才进入登录流程。

打开设置恢复当前账号最近查看的有权访问分类；直达链接优先于该记忆。退出后清理账号相关位置记忆，不跨账号复用。没有历史位置时进入账号与安全。设置页始终提供返回观看、当前身份和家庭管理锁定状态。

## 4. 核心验证方案

### 4.1 一个主要管理验证，不叠加设置 PIN

推荐：取消独立的“设置 PIN”验证步骤，使用账号密码解锁家庭管理。现有档案 PIN 保留用于共享设备选档和儿童隔离，不承担账号级管理权限。

进入家庭管理时：

1. 先检查当前登录会话、账号角色、当前主档案及服务端管理授权。
2. 已有有效授权：直接进入目标页，不显示验证弹层。
3. 无授权：显示一个“解锁家庭管理”面板，输入一次当前账号密码。
4. 本会话最近 5 分钟内刚完成账号密码登录或等价账号验证：用户仍需明确点击“解锁家庭管理”，服务器检查新鲜度后可签发授权，不重复索要同一密码。
5. 账号角色不足：解释没有管理权限，不反复弹凭据输入。
6. 当前不是主档案：明确提供“切换到主档案”入口；切换沿用选档保护。切换完成后继续管理意图，不额外再要求设置 PIN，也不静默切换身份。

用账号密码解锁使得知道主档案 PIN、但不知道账号密码的人无法自行获得管理权限。这是本次推荐的权限边界。

本期不额外提供“PIN 也能解锁全部管理”的平行模式，避免再次形成两套验证规则。Passkey 是后续增强项，需要单独设计注册、设备兼容和恢复能力；当前不能把按钮直接标成“Touch ID”或“Face ID”。

### 4.2 验证与确认矩阵

| 操作 | 需要管理解锁 | 额外凭据输入 | 确认方式 |
| --- | --- | --- | --- |
| 浏览设置外壳、已有的设备本地偏好 | 否 | 无 | 就地反馈 |
| 查看本人基本账号信息 | 否，仍需有效登录 | 无 | 无弹窗 |
| 查看家庭配置、来源、EPG、档案和策略 | 是 | 有效授权期间无 | 无弹窗 |
| 查询频道、筛选候选、测试来源、查看任务状态 | 是 | 无 | 行内加载与结果 |
| 创建/修改来源、导入、同步、保存 EPG 匹配 | 是 | 无 | 表单提交；异常发布单独确认 |
| 修改家庭名称、共享语言和家庭时区 | 是 | 无 | 显式保存，说明影响 |
| 创建档案、改名、默认观看档案 | 是 | 无 | 表单保存 |
| 修改等级与允许/禁止名单 | 是 | 无 | 显式保存，清楚标明目标档案 |
| 停用普通档案、停用来源 | 是 | 无 | 影响正在观看时说明后果并确认 |
| 查看设备播放记录 | 是 | 无 | 按设备查询，不进入公共/个人缓存 |
| 修改/清除/找回档案 PIN | 受限恢复或管理入口 | 当次账号密码 | 单个表单完成验证与变更 |
| 修改账号密码 | 有效会话及既有授权规则 | 当次当前密码 | 一张表单，不再先弹解锁或二次密码框 |
| 转移主档案、撤销设备会话 | 是 | 当次账号密码 | 一个弹层同时说明对象、后果并验证 |
| 导入结果包含显著删除或其他异常变更 | 是 | 无 | 一次发布确认，显示真实差异数量 |

内容权限保存会立即影响目标档案；通过目标名称、差异摘要和提交前权限检查防止误操作，不再以每次重复输密码补偿界面不清楚。

若用户直达一个高影响动作，验证面板应合并处理必要的管理授权和当次动作验证，不能出现“先解锁输密码，再确认同一动作又输密码”。密码通过后只执行用户明确提交的动作，不顺带执行其他等待中的动作。

### 4.3 管理授权期限

| 项目 | 推荐规则 |
| --- | --- |
| 空闲期限 | 15 分钟；只接受经服务端确认的前台用户管理操作刷新期限 |
| 最长期限 | 首次解锁后最多 60 分钟；达到上限需重新验证 |
| 不续期活动 | 后台任务轮询、自动刷新、页面保活、鼠标移动 |
| 返回/刷新 | 服务端授权仍有效则直接继续，不因页面重挂索要凭据 |
| 手动锁定 | 设置页提供“锁定家庭管理”，不退出观看登录 |
| 强制失效 | 退出、换档、会话/设备撤销、密码/PIN/主档案变化、档案停用、服务重启或恢复备份 |

共享设备上的代价：管理授权有效期间，能操作当前已解锁主档案的人可进行普通管理修改。通过主档案限制、空闲锁定、最长有效期和手动锁定控制这一窗口；不默认永久信任设备，不保存原始密码或 PIN。

所有期限和操作权限由服务端校验；客户端定时器只显示状态。服务端只保存有用途、期限和上下文绑定的授权记录，不复用原始密码。高影响动作的当次验证仅绑定本次对象、版本与动作，不能被转用于其他操作。

## 5. 完整页面交互

### 5.1 进入与返回

打开设置 → 恢复最近分类或深链接 → 家庭管理未解锁时显示一次解锁面板 → 解锁后保留原目标 → 设置内切换或短时返回不重复验证。

取消解锁回到原观看位置，或留在可访问的设置区域；不丢失观看页筛选、滚动位置和返回目标。网络错误显示“暂时无法核验，请重试”，不伪装成密码错误或已锁定。

### 5.2 保存与离开

- 文本表单、来源配置和内容权限采用显式保存。字段未变化时禁用保存。
- 设备本地、可撤销的简单偏好可以即时生效；这不扩大到家庭配置和权限修改。
- 等级与名单采用同一“保存内容权限”动作；一次提交同一目标的完整编辑差异，成功后只清理已提交字段。
- 修改尚未保存时，导航前提供“保存并离开 / 不保存 / 继续编辑”。保存需要验证时，仅在用户选“保存并离开”后进入验证。
- 验证取消、保存失败或版本冲突时留在原表单，保留输入。取消创建/关闭编辑面板同样检查是否真的有修改，打开空表单不算脏状态。
- 同页切换目标档案也视为离开当前编辑对象，需要相同保护。

### 5.3 到期与编辑恢复

到期前两分钟可显示非模态提示；用户正在连续操作时按服务端规则续期，不展示每秒倒计时。

到期后暂停新管理请求和轮询，隐藏受保护详情，保留当前会话中的非敏感编辑快照。提示“家庭管理已锁定，未保存的编辑已暂存”，提供“解锁继续”和“放弃编辑”。

非敏感草稿仅保留在当前页面会话内，不写入长期浏览器存储；密码、PIN、来源 URL 中的密钥等不保留。刷新或关闭页面有原生未保存提示，但本期不承诺刷新后恢复草稿。退出、换档、撤销或其他身份失效时清除草稿，不让另一身份恢复。

重新验证后读取服务器现值：版本未变可恢复非敏感编辑；版本变化展示“服务器现值 / 我的修改”，让用户合并或放弃。任何情况下都不自动重放保存请求。此前清除的敏感字段明确要求重填。

### 5.4 任务进行中

用户提交前冻结本次提交快照，提交中防止重复请求。长耗时导入转为后台任务，离开页面不取消服务器任务。返回时恢复任务状态。

授权到期不等于导入失败；界面说明“导入继续运行，解锁后查看结果”。网络断开后允许查询任务状态，不盲目创建重复任务。重新尝试同一次提交应复用幂等标识。

## 6. 各模块优化

| 模块 | 推荐流程与关键交互 |
| --- | --- |
| 账号与安全 | 基本信息 → 修改密码或管理档案 PIN。当前密码放在动作表单内。改密成功明确说明重新登录，清除旧身份与授权 |
| 档案管理 | 列表显示主档案、成人/儿童、默认与停用状态；创建/编辑在单个面板完成；禁用不合法操作并解释原因；转移主档案单次验证并明确影响 |
| 内容权限 | 先明确目标档案，再编辑等级、未评级与可搜索名单；显示名称和封面，不要求复制内部 ID；统一保存；冲突时保留草稿 |
| 媒体来源 | 选择类型 → 填写名称与地址/目录 → 保存并导入 → 展示任务 → 查看结果。支持仅保存；测试为可选操作，不要求再次验证；允许修正可修改字段 |
| 节目单 | 管理 EPG 来源 → 同步 → 为 IPTV 选择来源 → 按需手动匹配。优先关联来源、允许切换；搜索和筛选无验证弹窗；匹配后就地反馈 |
| 设备管理 | 明确标记当前设备、最近活跃与撤销状态；完整翻页查看记录；撤销当前设备时明确会退出；只在实际撤销提交时要求当次密码 |
| 通用设置 | 分开个人偏好与家庭配置；语言、时区使用搜索选择器；说明作用范围、实际支持与生效方式；不让用户猜测是否需要刷新 |

来源导入成功后的结果入口：IPTV → 直播，EPG → 节目单，NAS → 媒体库，VOD → 相应来源的在线内容入口。当前浏览页若不支持来源定位，应先说明跳转范围，不能声称已定位到该来源。

异常快照发布只展示真实差异：新增、更新、缺失及影响；需确认时解释原因。取消发布保留上次成功目录。任务状态采用“正在获取 / 等待确认 / 已完成 / 失败，可重试”等用户语言，错误码和版本进入可展开诊断详情。

## 7. 布局、反馈与可访问性

- 宽窗口保留侧栏，窄窗口收拢；标题始终显示当前分类，提供明显的返回入口。
- 任务内配置使用面板或抽屉承载；验证需要模态时只显示一层，不叠加弹窗。
- 普通成功采用行内状态或轻提示；只有不可逆、高影响和需立即决策的操作使用确认弹层。
- 失败区分字段校验、密码错误、网络故障、无权限、授权到期和版本冲突，分别给出有效动作。
- 焦点进入弹层并在关闭后返回；支持键盘操作与取消；验证失败聚焦错误或输入，不清空其他编辑。
- 长名称可换行或查看完整内容；200% 缩放和低高度窗口不遮住保存与取消按钮。
- 家庭节目时间按家庭时区显示并标注；设备活动时间按明确标注的显示时区转换。相对时间可辅助，不能掩盖准确时间。

## 8. 验证次数目标

下表统计的是凭据输入次数，不含普通保存按钮或发布确认；假设已登录且当前为主档案，无到期或身份变更。

| 场景 | 当前路径 | 提案目标 |
| --- | --- | --- |
| 新建来源后导入 | 设置 PIN 1 次，创建与导入账号密码各 1 次 | 最多账号密码 1 次；已解锁为 0 次 |
| 匹配一个频道，不额外筛选 | 设置 PIN 1 次，查询/打开匹配/保存账号密码共 3 次 | 最多账号密码 1 次；已解锁为 0 次 |
| 再搜索或筛选一次 EPG 候选 | 再输账号密码 | 0 次 |
| 同一管理授权内连续修改多个模块 | 每个敏感操作再次输入密码 | 普通管理操作新增 0 次 |
| 有效授权内离开再返回 | 规格要求 0 次，但两份前端状态存在重复提示风险 | 0 次 |
| 转移主档案、撤销设备 | 设置验证与当次密码可能分开 | 本次动作最多账号密码 1 次，不叠加设置 PIN |
| 修改账号密码 | 当前密码验证 | 当前密码 1 次，不新增前置验证 |

最近五分钟已完成账号级验证且满足上下文条件时，管理解锁可为零次凭据输入，但仍需明确点击解锁。普通档案切换到主档案可能另外涉及选档 PIN，不计入上表，也不等于重复设置验证。

## 9. 必须同步调整的规格与实现边界

现行 ADR-0011 与规格 005 FR-028、FR-030、FR-031、FR-033、FR-040、FR-041，以及相关 API/UI 契约明确要求独立设置 PIN、固定 15 分钟和敏感操作逐次密码。这些规则必须在方案接受后按替代关系更新，不能只在前端隐藏弹层。

实施需要：统一前端授权入口；服务端提供管理授权签发、核验、活动续期和撤销；区分普通管理与当次动作授权；每次请求重验角色、归属、身份版本与有效期；保留版本冲突、限流及失败锁定机制。

管理权限读取、设备记录与来源敏感信息不进入公共缓存；管理信息锁定时不继续可见。与当前公共浏览和个人观看权限保持明确边界。服务端授权测试和浏览器流程测试都必须补齐。

## 10. 实施顺序与验收

1. 接受授权分级与期限方案，更新 ADR/规格/API 契约，并确定敏感字段和高影响动作清单。
2. 修复重复 Provider、错误吞掉、草稿丢失、分页、EPG 来源选择等实现缺陷。
3. 接入新管理授权和合并验证流程，移除普通操作逐次密码弹层。
4. 整理七模块的任务流程、保存、错误和结果入口。
5. 完成服务端、浏览器、真实来源与共享设备场景验收。

关键验收条件：

- 同一有效管理授权内切换七个模块、返回和刷新不重复索要 PIN/密码。
- 页面解锁、菜单解锁与直达链接使用同一个授权事实；失败不误显示为成功。
- 创建来源、导入、测试、EPG 查询筛选和匹配不产生额外凭据输入。
- 普通查询、轮询不会让管理权限无限延长；空闲与最长有效期可用服务端可控时间测试。
- 普通/儿童档案、失效会话、撤销设备及跨家庭请求无法通过新授权读取或修改管理数据。
- 高影响动作仍需要当次验证；直达动作不产生两次密码输入；验证取消无写入。
- 继续编辑、保存失败、版本冲突和授权到期后，非敏感草稿符合本方案的恢复范围。
- 切换身份后不恢复旧身份草稿、不展示旧管理数据；敏感字段未进入持久缓存。
- 超过 20 个来源和 50 条设备记录可完整遍历；多 EPG 来源按明确选择匹配。
- 桌面、窄窗、低高度、200% 缩放与键盘操作均可完成验证、编辑、保存和取消。

本方案仅新增评审文档。未修改业务代码、现行规格或数据库，也未执行任何线上配置变更。
